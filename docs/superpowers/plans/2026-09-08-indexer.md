# A1 Stellar Indexer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `packages/indexer`, which reads the chain history of a set of
followed Stellar accounts from Horizon and writes validated `volume`,
`content` and `protocol` observations as NDJSON, with re-run safety, counted
drops and a measured delivery report.

**Architecture:** A thin Horizon client (rate limiter, cache, retention and
page-cap handling) feeds a `SourceReader` that normalises records into the
indexer's own types. Pure mappers turn those into `WireObservation`s per
channel; every observation passes `validateObservation`, then an in-run key
set, then an NDJSON sink. Counters record every read, write and drop with its
reason; a state file per network makes runs resumable.

**Tech Stack:** TypeScript on Node 22, pnpm 10 workspaces, vitest,
`@nonametrust/schema` (workspace), `@stellar/stellar-sdk` 17 (StrKey,
MuxedAccount, Keypair for tests). Node's `fetch` and `node:util` `parseArgs`;
no HTTP or CLI library.

**Spec:** `docs/superpowers/specs/2026-09-08-indexer-design.md`

## Global Constraints

- Node 22, pnpm 10 (`corepack pnpm`). TypeScript strict with `isolatedModules`
  and `exactOptionalPropertyTypes`: an optional field is omitted, never set to
  `undefined`.
- Every package's `tsconfig.json` copies the eight test-file exclusions from
  `packages/schema/tsconfig.json`; `tsconfig.test.json` sets `"exclude": []`.
- Run from the repository root in this order after any change to
  `packages/schema`: `pnpm build`, `pnpm typecheck`, `pnpm test`.
- A new package brings at least one test in the commit that creates it.
- **No Stellar account id shape in any tracked file** (`gates/no-stellar-address.test.ts`):
  no G+55 or M+68 base32 string, not in code, tests, fixtures, comments or
  docs. Tests generate keys with `Keypair.random()` at run time. Followed
  accounts, state, cache and output are gitignored.
- `Date.now()` appears in `packages/indexer` only in `clock.test.ts`.
- `datedAt` is the only reader of `observedAt`/`validFrom`/`validUntil` on
  an observation (`gates/single-date-reader.test.ts` on `m1-stores`, root
  scan of every `packages/*/src`). The indexer *writes* those fields when
  building observations; it never reads them off an observation. Keep the
  field names out of any non-mapper module.
- Producer name `stellar-indexer`, `producerVersion` `"0.1.0"`, `network`
  always `"stellar:pubnet"` or `"stellar:testnet"`, `schemaVersion` from
  `OBSERVATION_SCHEMA_VERSION`.
- All code, comments and docs in English. Commit messages are one sentence
  naming the property landed.
- Apache-2.0.

```ts
/**
 * Time enters the indexer through this interface and through no other route.
 * `Date.now()` appears in this package only in clock.test.ts, so a test can
 * run a thirty-day backfill against a fake source in milliseconds and the
 * rate limiter can be proved without sleeping.
 */
export interface Clock {
  now(): Date;
}

export const systemClock: Clock = {
  now: () => new Date(),
};

export interface FixedClock extends Clock {
  advance(ms: number): void;
}

export function fixedClock(start: Date): FixedClock {
  let t = start.getTime();
  return {
    now: () => new Date(t),
    advance: (ms: number) => {
      t += ms;
    },
  };
}
```

`packages/indexer/src/clock.test.ts`:

```ts
import { describe, it, expect } from "vitest";
import { fixedClock, systemClock } from "./clock.js";

describe("fixedClock", () => {
  it("does not move on its own", () => {
    const c = fixedClock(new Date("2026-09-08T00:00:00.000Z"));
    expect(c.now().getTime()).toBe(c.now().getTime());
  });

  it("advances by exactly what it is told", () => {
    const c = fixedClock(new Date("2026-09-08T00:00:00.000Z"));
    c.advance(30 * 24 * 60 * 60 * 1000);
    expect(c.now().toISOString()).toBe("2026-10-08T00:00:00.000Z");
  });

  it("hands out a copy, so mutating the answer does not move the clock", () => {
    const c = fixedClock(new Date("2026-09-08T00:00:00.000Z"));
    c.now().setFullYear(2000);
    expect(c.now().toISOString()).toBe("2026-09-08T00:00:00.000Z");
  });
});

describe("systemClock", () => {
  // The one permitted Date.now() in this package.
  it("returns a date near now", () => {
    expect(Math.abs(systemClock.now().getTime() - Date.now())).toBeLessThan(1000);
  });
});
```

`packages/indexer/src/counters.ts`:

```ts
/**
 * Every record the indexer reads ends as an observation or as a drop with a
 * reason from this list. A drop with no reason is a bug: the run fails at
 * exit if the identity records_read == written + dropped does not hold per
 * channel (run.ts). The list is closed so that a new reason is a decision
 * that shows up in the report, not a string someone typed once.
 */
export const DROP_REASONS = [
  "validation_failed",
  "memo_non_text",
  "memo_empty",
  "trustline_updated_skipped",
  "effect_ignored",
  "claimable_creator_unresolved",
  "sac_multi_asset",
  "sac_non_transfer",
  "invalid_account_id",
  "muxed_base_address",
  "self_payment",
  "unsupported_type",
  "not_followed",
  "duplicate_key_in_run",
] as const;
export type DropReason = (typeof DROP_REASONS)[number];

export interface CountersSnapshot {
  counts: Record<string, number>;
  drops: Record<string, number>;
  /** Up to ten refs per reason, in order of arrival, for a reader chasing a drop. */
  dropSamples: Record<string, string[]>;
}

const SAMPLE_LIMIT = 10;

export class Counters {
  private readonly counts = new Map<string, number>();
  private readonly dropCounts = new Map<DropReason, number>();
  private readonly samples = new Map<DropReason, string[]>();

  inc(name: string, by = 1): void {
    this.counts.set(name, (this.counts.get(name) ?? 0) + by);
  }

  get(name: string): number {
    return this.counts.get(name) ?? 0;
  }

  drop(reason: DropReason, ref: string): void {
    this.dropCounts.set(reason, (this.dropCounts.get(reason) ?? 0) + 1);
    const s = this.samples.get(reason) ?? [];
    if (s.length < SAMPLE_LIMIT) s.push(ref);
    this.samples.set(reason, s);
  }

  drops(): Record<string, number> {
    return sorted(this.dropCounts);
  }

  totalDrops(): number {
    let n = 0;
    for (const v of this.dropCounts.values()) n += v;
    return n;
  }

  snapshot(): CountersSnapshot {
    return {
      counts: sorted(this.counts),
      drops: sorted(this.dropCounts),
      dropSamples: sorted(this.samples),
    };
  }
}

function sorted<V>(m: Map<string, V>): Record<string, V> {
  const out: Record<string, V> = {};
  for (const k of [...m.keys()].sort()) out[k] = m.get(k) as V;
  return out;
}
```

```ts
import { MuxedAccount, StrKey } from "@stellar/stellar-sdk";
import type { AccountId } from "../source/types.js";

/**
 * The contract leaves two identity rules to the indexer and says so (section
 * 11, item 1): a wallet namespace id is a checksum-valid base account, and a
 * muxed address is resolved to its base with the sub-account id carried in
 * `muxedId`. The schema refuses the muxed shape from 0.2.0 on but never
 * checksums; these helpers are the indexer's gate for both.
 */
export function isBaseAccount(id: string): boolean {
  return StrKey.isValidEd25519PublicKey(id);
}

export function isMuxedAccount(id: string): boolean {
  return StrKey.isValidMed25519PublicKey(id);
}

export function resolveAccount(id: string): { base: AccountId; muxedId?: string } | null {
  if (isBaseAccount(id)) return { base: id };
  if (isMuxedAccount(id)) {
    const m = MuxedAccount.fromAddress(id, "0");
    return { base: m.baseAccount().accountId(), muxedId: m.id() };
  }
  return null;
}
```

```ts
 * `issuerKnown` on a protocol observation says whether the asset's issuer is
 * one the producer recognises (contract section 6). The list is short on
 * purpose and it holds sha256 digests of issuer addresses rather than the
 * addresses, because an issuer address is a Stellar account id and the root

 * looks the digest up.
 *
 * To add an entry: `printf '%s' "$ISSUER" | shasum -a 256`, and record where
 * the address was read from.
 */

  digest: string;
  assetCode: string;
  homeDomain: string;
  note: string;
}

  {
    // Circle's USDC on pubnet. Address read from horizon.stellar.org/assets?asset_code=USDC
    // on 2026-09-08 (the issuer with 2.39M authorized trustlines) and confirmed
    // against Circle's published Stellar issuer.

    assetCode: "USDC",
    homeDomain: "centre.io",
    note: "Circle USDC, pubnet",

];

}
```

```ts
import { OBSERVATION_SCHEMA_VERSION, type NamespaceRef, type WireObservation } from "@nonametrust/schema";
import type { AccountId, SourceAsset, SourcePayment } from "../source/types.js";
import { isBaseAccount } from "./address.js";
import { KINDS } from "./kinds.js";
import { source, type MapContext, type MapResult } from "./context.js";

/**
 * Value moved. Direction is relative to the followed namespace: "in" when
 * value reached it, "out" when it left (contract section 6). One chain
 * payment yields an "in" observation for the receiver and an "out" one for
 * the sender, and the idempotency key, which carries the namespace, keeps
 * both; this mapper produces only the followed side.
 *
 * `group` holds every SourcePayment of one operation. For the classic
 * payment family that is one record. For a Soroban invocation it is one
 * record per asset_balance_changes transfer, and several transfers to one
 * account in one invocation are summed into one observation, because the key
 * admits one observation per (ref, channel, namespace) and the operation id
 * is the ref (spec section 5.6). A second asset in the same invocation is a
 * drop with reason sac_multi_asset, reported rather than worked around.
 */
export function mapVolume(group: SourcePayment[], followed: AccountId, ctx: MapContext): MapResult[] {
  const first = group[0];
  if (!first) return [];
  const ref = `op:${first.opId}`;
  if (!isBaseAccount(followed)) return [{ ok: false, reason: "invalid_account_id", ref }];
  if (first.kind === "sac_transfer") return mapSac(group, followed, ctx, ref);
  return mapClassic(first, followed, ctx, ref);
}

function mapClassic(p: SourcePayment, followed: AccountId, ctx: MapContext, ref: string): MapResult[] {
  const isTo = p.to === followed;
  const isFrom = p.from === followed;
  if (!isTo && !isFrom) return [{ ok: false, reason: "not_followed", ref }];
  const out: MapResult[] = [];
  if (isTo) {
    out.push(build(p, followed, "in", p.amount, p.asset, p.toMuxedId, ctx, ref));
  }
  if (isFrom) {
    if (isTo) {
      out.push({ ok: false, reason: "self_payment", ref });
    } else {
      const amount = p.sourceAmount ?? p.amount;
      const asset = p.sourceAsset ?? p.asset;
      out.push(build(p, followed, "out", amount, asset, p.fromMuxedId, ctx, ref));
    }
  }
  return out;
}

function mapSac(group: SourcePayment[], followed: AccountId, ctx: MapContext, ref: string): MapResult[] {
  const out: MapResult[] = [];
  for (const direction of ["in", "out"] as const) {
    const mine = group.filter((p) => (direction === "in" ? p.to === followed : p.from === followed));
    if (mine.length === 0) continue;
    const firstAsset = mine[0]!.asset;
    const same = mine.filter((p) => sameAsset(p.asset, firstAsset));
    const other = mine.filter((p) => !sameAsset(p.asset, firstAsset));
    const total = same.reduce((acc, p) => addDecimal(acc, p.amount), "0");
    const muxed = direction === "in" ? mine[0]!.toMuxedId : mine[0]!.fromMuxedId;
    out.push(build(mine[0]!, followed, direction, total, firstAsset, muxed, ctx, ref));
    if (other.length > 0) out.push({ ok: false, reason: "sac_multi_asset", ref });
  }
  if (out.length === 0) out.push({ ok: false, reason: "not_followed", ref });
  return out;
}

function build(
  p: SourcePayment,
  followed: AccountId,
  direction: "in" | "out",
  amount: string,
  asset: SourceAsset,
  muxedId: string | undefined,
  ctx: MapContext,
  ref: string,
): MapResult {
  const namespace: NamespaceRef = muxedId === undefined
    ? { kind: "wallet", id: followed }
    : { kind: "wallet", id: followed, muxedId };
  const observation: WireObservation = {
    schemaVersion: OBSERVATION_SCHEMA_VERSION,
    namespace,
    channel: "volume",
    evidenceKind: "event",
    kind: kindOf(p),
    observedAt: p.createdAt,
    source: source(ctx, ref),
    payload: { amount, assetCode: asset.code, direction },
    salienceHints: { amount },
  };
  return { ok: true, observation };
}

function kindOf(p: SourcePayment): string {
  switch (p.kind) {
    case "payment": return KINDS.payment;
    case "path_payment": return KINDS.pathPayment;
    case "create_account": return KINDS.createAccount;
    case "sac_transfer": return KINDS.sacTransfer;
  }
}

function sameAsset(a: SourceAsset, b: SourceAsset): boolean {
  return a.code === b.code && a.issuer === b.issuer;
}

/**
 * Stellar amounts carry seven decimals and travel as strings; a JSON number
 * would round them. Summing is done on stroops (integers) and rendered back
 * without a leading zero and without trailing garbage, in the form the
 * schema's decimalStringSchema admits.
 */
export function addDecimal(a: string, b: string): string {
  const stroops = (s: string): bigint => {
    const [whole, frac = ""] = s.split(".");
    return BigInt(whole ?? "0") * 10_000_000n + BigInt((frac + "0000000").slice(0, 7));
  };
  const total = stroops(a) + stroops(b);
  const whole = total / 10_000_000n;
  const frac = (total % 10_000_000n).toString().padStart(7, "0");
  return `${whole}.${frac}`;
}
```

```ts
import { OBSERVATION_SCHEMA_VERSION, type WireObservation } from "@nonametrust/schema";
import type { AccountId, SourceMemo } from "../source/types.js";
import { isBaseAccount } from "./address.js";
import { KINDS } from "./kinds.js";
import { source, type MapContext, type MapResult } from "./context.js";

/**
 * A memo belongs to the transaction, not to the operation, so the reference
 * is the transaction hash and there is one content observation per
 * (transaction, followed namespace). One per payment operation would emit the
 * same text once per operation and the tagging pipeline would count one memo
 * as several (spec section 5.3; proposed to the contract as the answer to its
 * first open point).
 *
 * Only text memos carry evidence. `id`, `hash` and `return` memos are
 * counted and not mapped; an empty text memo likewise.
 */
export function mapContent(memo: SourceMemo, followed: AccountId, createdAt: string, ctx: MapContext): MapResult {
  const ref = `tx:${memo.txHash}`;
  if (!isBaseAccount(followed)) return { ok: false, reason: "invalid_account_id", ref };
  if (memo.type !== "text") return { ok: false, reason: "memo_non_text", ref };
  const text = memo.text ?? "";
  if (text.length === 0) return { ok: false, reason: "memo_empty", ref };
  const observation: WireObservation = {
    schemaVersion: OBSERVATION_SCHEMA_VERSION,
    namespace: { kind: "wallet", id: followed },
    channel: "content",
    evidenceKind: "event",
    kind: KINDS.memo,
    observedAt: createdAt,
    source: source(ctx, ref),
    payload: { text, field: "memo" },
  };
  return { ok: true, observation };
}
```

```ts
import { OBSERVATION_SCHEMA_VERSION, type ProtocolPayload, type WireObservation } from "@nonametrust/schema";
import type { SourceAsset, SourceEffect } from "../source/types.js";
import { isBaseAccount } from "./address.js";
import { KINDS } from "./kinds.js";
import { KNOWN_ISSUERS, isKnownIssuer, type KnownIssuer } from "./issuers.js";
import { source, type MapContext, type MapResult } from "./context.js";

/**
 * Protocol-level facts about the followed account (contract section 6).
 * `payload.event` is Horizon's effect name verbatim; `kind` is ours. A
 * trustline that opens is a state and never rewritten; its closing is a
 * separate event with the closing operation's own reference. `issuerKnown`
 * is written on every observation that carries an asset, never left absent,
 * because the airdrop trap turns on issuerKnown === false and an absent
 * field would read as "unknown" rather than "unknown issuer".
 */
export function mapProtocol(
  e: SourceEffect,
  ctx: MapContext,
  issuers: readonly KnownIssuer[] = KNOWN_ISSUERS,
): MapResult {
  const ref = `op:${e.opId}`;
  if (!isBaseAccount(e.account)) return { ok: false, reason: "invalid_account_id", ref };
  const base = {
    schemaVersion: OBSERVATION_SCHEMA_VERSION,
    namespace: { kind: "wallet" as const, id: e.account },
    channel: "protocol" as const,
    source: source(ctx, ref),
  };
  switch (e.type) {
    case "trustline_created": {
      const observation: WireObservation = {
        ...base,
        evidenceKind: "state",
        kind: KINDS.trustlineOpen,
        validFrom: e.createdAt,
        validUntil: null,
        payload: assetPayload("trustline_created", e.asset, issuers),
      };
      return { ok: true, observation };
    }
    case "trustline_removed":
      return event(base, KINDS.trustlineClosed, e.createdAt, assetPayload("trustline_removed", e.asset, issuers));
    case "trustline_updated":
      return { ok: false, reason: "trustline_updated_skipped", ref };
    case "claimable_balance_claimant_created":
      return event(base, KINDS.claimableBalanceOffered, e.createdAt, assetPayload(e.type, e.asset, issuers));
    case "account_flags_updated":
      return event(base, KINDS.accountFlagsChanged, e.createdAt, { event: "account_flags_updated" });
  }
}

function event(
  base: Pick<WireObservation, "schemaVersion" | "namespace" | "channel" | "source">,
  kind: string,
  observedAt: string,
  payload: ProtocolPayload,
): MapResult {
  const observation: WireObservation = { ...base, evidenceKind: "event", kind, observedAt, payload };
  return { ok: true, observation };
}

function assetPayload(eventName: string, asset: SourceAsset | undefined, issuers: readonly KnownIssuer[]): ProtocolPayload {
  if (!asset) return { event: eventName };
  if (asset.issuer === null) return { event: eventName, assetCode: asset.code, issuerKnown: true };
  return {
    event: eventName,
    assetCode: asset.code,
    assetIssuer: asset.issuer,
    issuerKnown: isKnownIssuer(asset.issuer, issuers),
  };
}
```

```ts
import { createReadStream } from "node:fs";
import { createInterface } from "node:readline";

/**
 * Deduplication is a correctness property: a duplicated trace makes the
 * tagging pipeline believe the evidence is twice as strong. Within a run the
 * key set catches a repeat, which is a defect (spec 5.6) and fails the run.
 * Across runs the delivery test compares two files' key sets and expects
 * both differences empty.
 */
export class KeySet {
  private readonly set = new Set<string>();
  add(key: string): boolean {
    if (this.set.has(key)) return false;
    this.set.add(key);
    return true;
  }
  has(key: string): boolean {
    return this.set.has(key);
  }
  size(): number {
    return this.set.size;
  }
  keys(): string[] {
    return [...this.set];
  }
}

export async function readKeys(ndjsonPath: string): Promise<Set<string>> {
  const keys = new Set<string>();
  const rl = createInterface({ input: createReadStream(ndjsonPath, "utf8"), crlfDelay: Infinity });
  let n = 0;
  for await (const line of rl) {
    n++;
    if (line.trim().length === 0) continue;
    const parsed = JSON.parse(line) as { idempotencyKey?: unknown };
    if (typeof parsed.idempotencyKey !== "string") {
      throw new Error(`${ndjsonPath} line ${n}: no idempotencyKey; not a validated observation`);
    }
    keys.add(parsed.idempotencyKey);
  }
  return keys;
}

export function compareKeys(previous: Set<string>, current: Set<string>): { onlyInPrevious: string[]; onlyInCurrent: string[] } {
  return {
    onlyInPrevious: [...previous].filter((k) => !current.has(k)).sort(),
    onlyInCurrent: [...current].filter((k) => !previous.has(k)).sort(),
  };
}
```

```ts
  const day = (iso: string) => iso.slice(0, 10);

export interface Sink {
  write(line: object): void;
  close(): Promise<{ lines: number; path: string }>;
}

export function openSink(path: string): Sink {
  mkdirSync(dirname(path), { recursive: true });
  const stream = createWriteStream(path, { encoding: "utf8" });
  let lines = 0;
  return {
    write(line) {
      stream.write(JSON.stringify(line) + "\n");
      lines++;
    },
    close() {
      return new Promise((resolve, reject) => {
        stream.end((err?: Error | null) => (err ? reject(err) : resolve({ lines, path })));
      });
    },
  };
}
```

```ts
import { mkdir, readFile, rename, writeFile } from "node:fs/promises";
import { dirname } from "node:path";
import type { Network } from "./mapper/context.js";
import type { AccountId, LedgerRange } from "./source/types.js";

/**
 * The indexer ends in shadow mode, so it resumes rather than restarts. The
 * state holds, per followed account, the last cursor consumed on each
 * stream and the ranges completed. It is written after every page (run.ts),
 * so a kill loses at most one page and never leaves a gap. It names accounts
 * and is therefore gitignored.
 */
export interface AccountState {
  paymentsCursor?: string;
  effectsCursor?: string;
  completed: LedgerRange[];
}

export interface IndexerState {
  network: Network;
  retentionFloor?: number;
  accounts: Record<AccountId, AccountState>;
}

export async function loadState(path: string, network: Network): Promise<IndexerState> {
  let raw: string;
  try {
    raw = await readFile(path, "utf8");
  } catch (e) {
    if ((e as { code?: string }).code === "ENOENT") return { network, accounts: {} };
    throw e;
  }
  const parsed = JSON.parse(raw) as IndexerState;
  if (parsed.network !== network) {
    throw new Error(`${path} was written for ${parsed.network}, not ${network}`);
  }
  return parsed;
}

export async function saveState(path: string, state: IndexerState): Promise<void> {
  await mkdir(dirname(path), { recursive: true });
  const tmp = `${path}.tmp`;
  await writeFile(tmp, JSON.stringify(state, null, 2) + "\n", "utf8");
  await rename(tmp, path);
}

export function isCompleted(state: AccountState, range: LedgerRange): boolean {
  return state.completed.some((c) => c.from <= range.from && c.to >= range.to);
}

export function markCompleted(state: AccountState, range: LedgerRange): void {
  if (!isCompleted(state, range)) state.completed.push({ from: range.from, to: range.to });
}
```

```ts
const DEFAULT_MAX_RETRIES = 5;

/**
 * A thin client: every trap the backtest measured lives at this layer and
 * must be visible, so there is no library between us and HTTP. Time comes
 * from the injected clock and waiting from the injected sleep, so the
 * limiter is proved under a fake clock.
 */
export class HorizonClient {
  private readonly fetchImpl: typeof fetch;
  private readonly sleep: (ms: number) => Promise<void>;
  private readonly minIntervalMs: number;
  private readonly maxRetries: number;
  private lastRequestAt = Number.NEGATIVE_INFINITY;

  constructor(private readonly opts: HorizonClientOptions) {
    this.fetchImpl = opts.fetch ?? fetch;
    this.sleep = opts.sleep ?? ((ms) => new Promise((r) => setTimeout(r, ms)));
    this.minIntervalMs = opts.minIntervalMs ?? DEFAULT_MIN_INTERVAL_MS;
    this.maxRetries = opts.maxRetries ?? DEFAULT_MAX_RETRIES;
    if (opts.cacheDir) mkdirSync(opts.cacheDir, { recursive: true });
  }

  async getJson<T = unknown>(pathWithQuery: string): Promise<T> {
    const url = pathWithQuery.startsWith("http") ? pathWithQuery : `${this.opts.baseUrl}${pathWithQuery}`;
    const cached = this.readCache(url);
    if (cached !== null) {
      this.opts.counters.inc("cache_hits");
      return JSON.parse(cached) as T;
    }
    let attempt = 0;
    for (;;) {
      await this.throttle();
      this.opts.counters.inc("requests");
      const res = await this.fetchImpl(url, { headers: { accept: "application/json" } });
      if (res.status === 200) {
        const text = await res.text();
        this.writeCache(url, text);
        return JSON.parse(text) as T;
      }
      if (res.status === 410) {
        this.opts.counters.inc("retention_refusals");
        throw new RetentionBoundary(`Horizon no longer serves ${url} (HTTP 410)`, url);
      }
      const retryable = res.status === 429 || res.status >= 500;
      if (!retryable || attempt >= this.maxRetries) {
        throw new Error(`Horizon ${res.status} for ${url}`);
      }
      attempt++;
      this.opts.counters.inc("retries");
      await this.sleep(this.minIntervalMs * 2 ** attempt);
    }
  }

  /**
   * Follows `_links.next` until a page comes back empty. A page shorter than
   * the requested limit that is nonetheless followed by records is counted
   * as truncated, because that is the shape the backtest saw when Horizon
   * cut a page silently; nothing is lost, since the next link is followed
   * regardless, but the report must say it happened.
   */
  async *pages<T>(pathWithQuery: string): AsyncIterable<T[]> {
    const limit = requestedLimit(pathWithQuery);
    let url: string | null = pathWithQuery;
    let previousShort = false;
    while (url !== null) {
      const raw: RawPage<T> = await this.getJson<RawPage<T>>(url);
      const records = raw._embedded?.records ?? [];
      if (records.length === 0) return;
      if (previousShort) this.opts.counters.inc("pages_truncated");
      yield records;
      previousShort = limit !== null && records.length < limit;
      url = raw._links?.next?.href ?? null;
    }
  }

  private async throttle(): Promise<void> {
    const now = this.opts.clock.now().getTime();
    const wait = this.lastRequestAt + this.minIntervalMs - now;
    if (wait > 0) await this.sleep(wait);
    this.lastRequestAt = this.opts.clock.now().getTime();
  }

  private cachePath(url: string): string | null {
    if (!this.opts.cacheDir) return null;
    return join(this.opts.cacheDir, createHash("sha256").update(url).digest("hex") + ".json");
  }

  private readCache(url: string): string | null {
    const p = this.cachePath(url);
    if (p === null || !existsSync(p)) return null;
    return readFileSync(p, "utf8");
  }

  private writeCache(url: string, text: string): void {
    const p = this.cachePath(url);
    if (p !== null) writeFileSync(p, text, "utf8");
  }
}

function requestedLimit(url: string): number | null {
  const m = /[?&]limit=(\d+)/.exec(url);
  return m ? Number(m[1]) : null;
}
```

```ts
/**
 * Overrides may carry `undefined` to remove a default field (a create_account
 * record has no `from`), which `Partial<T>` forbids under
 * exactOptionalPropertyTypes; the builders strip undefined keys.

type Overrides<T> = { [K in keyof T]?: T[K] | undefined };

function withOverrides<T extends object>(base: T, over: Overrides<T>): T {
  const out = { ...base } as Record<string, unknown>;

    else out[k] = v;
  }
  return out as T;
}

/**
 * Horizon's cursor means "records after this paging token". A cursor that is
 * no record's token (cursorForLedger gives one) starts at the first record
 * whose token, read as the integer before any dash, is greater.
 */
function startIndex(all: Array<{ paging_token: string }>, cursor: string | null): number {
  if (cursor === null) return 0;
  const exact = all.findIndex((r) => r.paging_token === cursor);
  if (exact >= 0) return exact + 1;
  const c = BigInt(cursor.split("-")[0] ?? "0");
  const i = all.findIndex((r) => BigInt(r.paging_token.split("-")[0] ?? "0") > c);
  return i < 0 ? all.length : i;
}

/**
 * A fake Horizon that pages a fixed list per path in pages of `limit`,
 * honouring order=asc|desc and cursor. Routes are keyed by the path before
 * the query string; a route may also be a fixed status and body, for 404,
 * 410 and single-resource endpoints.
 */
export function fakeHorizon(
  routes: Record<string, unknown[] | { status: number; body?: unknown }>,
): typeof fetch {
  return (async (input: string | URL | Request) => {
    const url = new URL(String(input));
    const route = routes[url.pathname];
    if (route === undefined) return new Response("{}", { status: 404 });
    if (!Array.isArray(route)) return new Response(JSON.stringify(route.body ?? {}), { status: route.status });
    const limit = Number(url.searchParams.get("limit") ?? "10");
    const cursor = url.searchParams.get("cursor");
    let all = route as Array<{ paging_token: string }>;
    if (url.searchParams.get("order") === "desc") all = [...all].reverse();
    const start = startIndex(all, cursor);
    const records = all.slice(start, start + limit);
    const last = records[records.length - 1];
    const next = new URL(url);
    if (last) next.searchParams.set("cursor", last.paging_token);
    const body = { _links: { next: { href: next.toString() } }, _embedded: { records } };
    return new Response(JSON.stringify(body), { status: 200 });
  }) as typeof fetch;
}
```

```ts
  "trustline_created", "trustline_removed", "trustline_updated",
  "claimable_balance_claimant_created", "account_flags_updated",

/** A Horizon operation id is (ledger << 32) | (tx index << 12) | op index. */
export function ledgerOfOperation(opId: string): number {
  return Number(BigInt(opId) >> 32n);
}

/** The first possible operation id of a ledger, usable as a paging cursor. */
export function cursorForLedger(ledger: number): string {
  return (BigInt(ledger) << 32n).toString();
}

function ledgerOfEffect(effectId: string): number {
  return ledgerOfOperation(effectId.split("-")[0] ?? "0");
}

function opOfEffect(effectId: string): string {
  return BigInt(effectId.split("-")[0] ?? "0").toString();
}

function toIso(horizonTime: string): string {
  return new Date(horizonTime).toISOString();
}

function asset(assetType: string | undefined, code: string | undefined, issuer: string | undefined): SourceAsset {
  if (assetType === "native" || assetType === undefined) return { code: "XLM", issuer: null };
  return { code: code ?? "", issuer: issuer ?? null };
}

function assetFromString(s: string): SourceAsset {
  if (s === "native") return { code: "XLM", issuer: null };
  const [code, issuer] = s.split(":");
  return { code: code ?? "", issuer: issuer ?? null };
}

/**
 * Horizon behind the SourceReader seam. Reads oldest-first from the range's
 * first possible operation id, stops at the first record past the range, and
 * refuses a range that starts before the retention floor rather than
 * reporting it empty (spec section 11).
 */
export class HorizonReader implements SourceReader {
  constructor(private readonly client: HorizonClient, private readonly counters: Counters) {}

  async *payments(account: AccountId, range: LedgerRange): AsyncIterable<SourcePayment> {
    await this.assertServed(range);
    const path = `/accounts/${account}/payments?order=asc&limit=${PAGE_LIMIT}&join=transactions&cursor=${cursorForLedger(range.from)}`;
    for await (const page of this.client.pages<HorizonPaymentRecord>(path)) {
      for (const rec of page) {
        const ledger = ledgerOfOperation(rec.id);
        if (ledger > range.to) return;
        if (ledger < range.from) continue;
        this.counters.inc(`records_read.${rec.type}`);
        if (!rec.transaction_successful) {
          this.counters.inc("records_failed_tx");
          continue;
        }
        yield* this.normalisePayment(rec, ledger);
      }
    }
  }

  private *normalisePayment(rec: HorizonPaymentRecord, ledger: number): Iterable<SourcePayment> {
    const base = {
      opId: rec.id, ledger, txHash: rec.transaction_hash, createdAt: toIso(rec.created_at),
    };
    const memo = rec.transaction ? memoOf(rec.transaction) : undefined;
    const withMemo = <T extends object>(p: T): T & { memo?: SourceMemo } => (memo ? { ...p, memo } : p);
    switch (rec.type) {
      case "payment":
      case "path_payment_strict_send":
      case "path_payment_strict_receive": {
        const from = side(rec.from, rec.from_muxed_id);
        const to = side(rec.to, rec.to_muxed_id);
        if (!from || !to) { this.counters.drop("invalid_account_id", `op:${rec.id}`); return; }
        const p: SourcePayment = withMemo({
          ...base,
          kind: rec.type === "payment" ? "payment" : "path_payment",
          from: from.base, to: to.base,
          ...(from.muxedId !== undefined ? { fromMuxedId: from.muxedId } : {}),
          ...(to.muxedId !== undefined ? { toMuxedId: to.muxedId } : {}),
          amount: rec.amount ?? "0",
          asset: asset(rec.asset_type, rec.asset_code, rec.asset_issuer),
          ...(rec.type === "payment" ? {} : {
            sourceAmount: rec.source_amount ?? "0",
            sourceAsset: asset(rec.source_asset_type, rec.source_asset_code, rec.source_asset_issuer),
          }),
        });
        yield p;
        return;
      }
      case "create_account": {
        const from = side(rec.funder, undefined);
        const to = side(rec.account, undefined);
        if (!from || !to) { this.counters.drop("invalid_account_id", `op:${rec.id}`); return; }
        yield withMemo({
          ...base, kind: "create_account", from: from.base, to: to.base,
          amount: rec.starting_balance ?? "0", asset: { code: "XLM", issuer: null },
        });
        return;
      }
      case "invoke_host_function": {
        const changes = rec.asset_balance_changes ?? [];
        for (const [i, c] of changes.entries()) {
          if (c.type !== "transfer") { this.counters.drop("sac_non_transfer", `op:${rec.id}#${i}`); continue; }
          const from = side(c.from, undefined);
          const to = side(c.to, c.destination_muxed_id);
          if (!from || !to) { this.counters.drop("invalid_account_id", `op:${rec.id}#${i}`); continue; }
          yield withMemo({
            ...base, kind: "sac_transfer", from: from.base, to: to.base,
            ...(to.muxedId !== undefined ? { toMuxedId: to.muxedId } : {}),
            amount: c.amount, asset: asset(c.asset_type, c.asset_code, c.asset_issuer), transferIndex: i,
          });
        }
        return;
      }
      default:
        this.counters.drop("unsupported_type", `op:${rec.id}`);
    }
  }

  async *effects(account: AccountId, range: LedgerRange): AsyncIterable<SourceEffect> {
    await this.assertServed(range);
    const path = `/accounts/${account}/effects?order=asc&limit=${PAGE_LIMIT}&cursor=${cursorForLedger(range.from)}-0`;
    for await (const page of this.client.pages<HorizonEffectRecord>(path)) {
      for (const rec of page) {
        const ledger = ledgerOfEffect(rec.id);
        if (ledger > range.to) return;
        if (ledger < range.from) continue;
        this.counters.inc(`effects_read.${rec.type}`);
        if (!EFFECT_TYPES.has(rec.type)) { this.counters.drop("effect_ignored", `effect:${rec.id}`); continue; }
        const e: SourceEffect = {
          effectId: rec.id, opId: opOfEffect(rec.id), ledger, createdAt: toIso(rec.created_at),
          account: rec.account, type: rec.type as EffectType,
        };
        if (rec.asset !== undefined) e.asset = assetFromString(rec.asset);
        else if (rec.asset_type !== undefined) e.asset = asset(rec.asset_type, rec.asset_code, rec.asset_issuer);
        if (rec.amount !== undefined) e.amount = rec.amount;
        yield e;
      }
    }
  }

  async memo(txHash: string): Promise<SourceMemo | null> {
    try {
      const tx = await this.client.getJson<{ hash: string; memo_type: string; memo?: string }>(`/transactions/${txHash}`);
      return memoOf(tx);
    } catch (e) {
      if (e instanceof Error && /404/.test(e.message)) return null;
      throw e;
    }
  }

  async retentionFloor(): Promise<number> {
    const page = await this.client.getJson<{ _embedded: { records: Array<{ sequence: number }> } }>("/ledgers?order=asc&limit=1");
    const first = page._embedded.records[0];
    if (!first) throw new Error("Horizon returned no ledgers");
    return first.sequence;
  }

  async latestLedger(): Promise<number> {
    const page = await this.client.getJson<{ _embedded: { records: Array<{ sequence: number }> } }>("/ledgers?order=desc&limit=1");
    const last = page._embedded.records[0];
    if (!last) throw new Error("Horizon returned no ledgers");
    return last.sequence;
  }

  /**
   * Instants to ledger sequences, by bisection over /ledgers/{seq}. About
   * twenty-five requests per bound on a fourteen-month window; cached, so a
   * repeated run pays nothing.
   */
  async resolveRange(fromIso: string, toIso: string): Promise<LedgerRange> {
    const floor = await this.retentionFloor();
    const latest = await this.latestLedger();
    const closedAt = async (seq: number): Promise<number> => {
      const l = await this.client.getJson<{ closed_at: string }>(`/ledgers/${seq}`);
      return Date.parse(l.closed_at);
    };
    // First ledger closed at or after `t`.
    const firstAtOrAfter = async (t: number): Promise<number> => {
      let lo = floor, hi = latest;
      while (lo < hi) {
        const mid = Math.floor((lo + hi) / 2);
        if ((await closedAt(mid)) >= t) hi = mid; else lo = mid + 1;
      }
      return lo;
    };
    const from = await firstAtOrAfter(Date.parse(fromIso));
    const to = (await firstAtOrAfter(Date.parse(toIso))) - 1;
    if (from > to) throw new Error(`empty range: ${fromIso} to ${toIso} covers no ledger`);
    return { from, to };
  }

  /** All payment-family records on the network inside the range; for account selection. */
  async *globalPayments(range: LedgerRange): AsyncIterable<SourcePayment> {
    await this.assertServed(range);
    const path = `/payments?order=asc&limit=${PAGE_LIMIT}&cursor=${cursorForLedger(range.from)}`;
    for await (const page of this.client.pages<HorizonPaymentRecord>(path)) {
      for (const rec of page) {
        const ledger = ledgerOfOperation(rec.id);
        if (ledger > range.to) return;
        if (ledger < range.from || !rec.transaction_successful) continue;
        yield* this.normalisePayment(rec, ledger);
      }
    }
  }

  async accountExists(id: AccountId): Promise<boolean> {
    try {
      await this.client.getJson(`/accounts/${id}`);
      return true;
    } catch (e) {
      if (e instanceof Error && /404/.test(e.message)) return false;
      throw e;
    }
  }

  private floorCache: number | null = null;
  private async assertServed(range: LedgerRange): Promise<void> {
    if (this.floorCache === null) this.floorCache = await this.retentionFloor();
    if (range.from < this.floorCache) {
      this.counters.inc("retention_refusals");
      throw new RetentionBoundary(
        `range starts at ledger ${range.from}, Horizon serves from ${this.floorCache}`,
        "/ledgers?order=asc&limit=1",
      );
    }
  }
}

function side(id: string | undefined, muxedId: string | undefined): { base: AccountId; muxedId?: string } | null {
  if (id === undefined) return null;
  const r = resolveAccount(id);
  if (r === null) return null;
  if (muxedId !== undefined) return { base: r.base, muxedId };
  return r;
}

function memoOf(tx: { hash: string; memo_type: string; memo?: string }): SourceMemo {
  const type = (["none", "text", "id", "hash", "return"].includes(tx.memo_type) ? tx.memo_type : "none") as MemoType;
  return type === "text" ? { txHash: tx.hash, type, text: tx.memo ?? "" } : { txHash: tx.hash, type };
}
```

`KeySet.add` (drop `duplicate_key_in_run` on repeat), then `sink.write`;
every `ok: false` is `counters.drop(reason, ref)`; `records_read` and
`observations_written.<channel>` are counted; state is saved after each
account (the reader's page boundary is inside the async iterator, so
"after every page" becomes "after every account" in v0; recorded as a limit).

```ts
import { validateObservation } from "@nonametrust/schema";
import type { Clock } from "./clock.js";
import type { Counters } from "./counters.js";
import { KeySet } from "./dedupe.js";
import type { MapContext, MapResult } from "./mapper/context.js";
import { mapContent } from "./mapper/content.js";
import { mapProtocol } from "./mapper/protocol.js";
import { mapVolume } from "./mapper/volume.js";
import type { Sink } from "./sink.js";
import type { SourceReader } from "./source/reader.js";
import type { AccountId, LedgerRange, SourcePayment } from "./source/types.js";
import { isCompleted, markCompleted, type IndexerState } from "./state.js";

export interface BackfillOptions {
  reader: SourceReader;
  accounts: AccountId[];
  range: LedgerRange;
  ctx: Omit<MapContext, "fetchedAt">;
  sink: Sink;
  state: IndexerState;
  saveState: () => Promise<void>;
  counters: Counters;
  clock: Clock;
  force?: boolean;
}

export interface BackfillResult {
  written: number;
  accountsDone: number;
  accountsSkipped: number;
  duplicateKeys: number;
}

/**
 * read -> map -> validate -> dedupe -> sink, per followed account. Every
 * record ends as a written observation or a counted drop with a reason;
 * nothing is skipped silently. The state is saved after each account, so a
 * kill loses at most one account's partial work and never leaves a gap.
 */
export async function backfill(o: BackfillOptions): Promise<BackfillResult> {
  const keys = new KeySet();
  const result: BackfillResult = { written: 0, accountsDone: 0, accountsSkipped: 0, duplicateKeys: 0 };
  o.counters.inc("accounts_followed", o.accounts.length);

  for (const account of o.accounts) {
    const accountState = (o.state.accounts[account] ??= { completed: [] });
    if (!o.force && isCompleted(accountState, o.range)) {
      result.accountsSkipped++;
      continue;
    }
    const ctx: MapContext = { ...o.ctx, fetchedAt: o.clock.now().toISOString() };
    const emit = (r: MapResult): void => {
      if (!r.ok) {
        o.counters.drop(r.reason, r.ref);
        return;
      }
      const v = validateObservation(r.observation);
      if (!v.ok) {
        o.counters.drop("validation_failed", `${r.observation.source.ref} ${v.errors[0] ?? ""}`);
        return;
      }
      if (!keys.add(v.value.idempotencyKey)) {
        o.counters.drop("duplicate_key_in_run", r.observation.source.ref);
        result.duplicateKeys++;
        return;
      }
      o.sink.write(v.value);
      o.counters.inc(`observations_written.${v.value.channel}`);
      result.written++;
    };

    // Payments, grouped by operation so Soroban transfers are summed; memos once per transaction.
    let group: SourcePayment[] = [];
    const memoSeen = new Set<string>();
    const flush = (): void => {
      if (group.length === 0) return;
      for (const r of mapVolume(group, account, ctx)) emit(r);
      group = [];
    };
    for await (const p of o.reader.payments(account, o.range)) {
      o.counters.inc("records_read.payments");
      if (p.toMuxedId !== undefined || p.fromMuxedId !== undefined) o.counters.inc("muxed_records");
      if (group.length > 0 && group[0]!.opId !== p.opId) flush();
      group.push(p);
      if (p.memo && !memoSeen.has(p.txHash)) {
        memoSeen.add(p.txHash);
        o.counters.inc("records_read.memos");
        emit(mapContent(p.memo, account, p.createdAt, ctx));
      }
    }
    flush();

    for await (const e of o.reader.effects(account, o.range)) {
      o.counters.inc("records_read.effects");
      emit(mapProtocol(e, ctx));
    }

    markCompleted(accountState, o.range);
    await o.saveState();
    result.accountsDone++;
  }
  return result;
}
```

```ts
import { createHash } from "node:crypto";
import type { AccountId, LedgerRange, SourcePayment } from "./source/types.js";

/**
 * The followed accounts for the 100-account backfill are ordinary active
 * wallets chosen by a rule, because the list itself cannot be tracked (it is
 * made of account ids) and the population must be reproducible by anyone
 * from the rule and the ledger range (spec section 9). Accounts that appear
 * too often in the sample window have the exchange and service profile the
 * backtest excluded; they are dropped. The rest are ordered by the digest of
 * their id, which is a fixed order that favours nobody.
 */
export interface SelectionSource {
  globalPayments(range: LedgerRange): AsyncIterable<SourcePayment>;
  accountExists(id: AccountId): Promise<boolean>;
}

export interface SelectionOptions {
  range: LedgerRange;
  n: number;
  maxAppearances: number;
}

export interface SelectionResult {
  accounts: AccountId[];
  candidates: number;
  excludedBusy: number;
  excludedMissing: number;
}

export function orderKey(account: AccountId): string {
  return createHash("sha256").update(account).digest("hex");
}

export async function selectAccounts(source: SelectionSource, opts: SelectionOptions): Promise<SelectionResult> {
  const appearances = new Map<AccountId, number>();
  for await (const p of source.globalPayments(opts.range)) {
    if (p.kind === "sac_transfer") continue;
    for (const a of [p.from, p.to]) appearances.set(a, (appearances.get(a) ?? 0) + 1);
  }
  const result: SelectionResult = { accounts: [], candidates: appearances.size, excludedBusy: 0, excludedMissing: 0 };
  const ordered = [...appearances.entries()]
    .filter(([, n]) => {
      const keep = n <= opts.maxAppearances;
      if (!keep) result.excludedBusy++;
      return keep;
    })
    .map(([a]) => a)
    .sort((x, y) => orderKey(x).localeCompare(orderKey(y)));
  for (const a of ordered) {
    if (result.accounts.length >= opts.n) break;
    if (await source.accountExists(a)) result.accounts.push(a);
    else result.excludedMissing++;
  }
  return result;
}
```

```ts
import type { CountersSnapshot } from "./counters.js";
import type { Network } from "./mapper/context.js";
import type { LedgerRange } from "./source/types.js";

export interface ReportMeta {
  network: Network;
  fromIso: string;
  toIso: string;
  range: LedgerRange;
  retentionFloor: number;
  runDate: string;
  accounts: number;
  wallClockMs: number;
  compare?: { previous: string; onlyInPrevious: number; onlyInCurrent: number };
}

const STRKEY = /G[A-Z2-7]{55}|M[A-Z2-7]{68}|g[a-z2-7]{55}|m[a-z2-7]{68}/g;

/**
 * The delivery table of the developer brief (section 7), filled from the
 * counters. Aggregates only: every string that reaches the output is scrubbed
 * of the account-id shape, so a drop sample that carried an id cannot leak
 * it into a file that someone then commits or pastes.
 */
export function renderReport(snapshot: CountersSnapshot, meta: ReportMeta): { json: string; markdown: string } {
  const scrubbed: CountersSnapshot = {
    counts: snapshot.counts,
    drops: snapshot.drops,
    dropSamples: Object.fromEntries(
      Object.entries(snapshot.dropSamples).map(([k, v]) => [k, v.map((s) => s.replace(STRKEY, "<account>"))]),
    ),
  };
  const c = scrubbed.counts;
  const read = c["records_read.payments"] ?? 0;
  const written = c["observations_written.volume"] ?? 0;
  const ratio = read === 0 ? 0 : written / read;
  const muxed = c["muxed_records"] ?? 0;
  const totalObs = Object.entries(c).filter(([k]) => k.startsWith("observations_written.")).reduce((a, [, v]) => a + v, 0);
  const requests = c["requests"] ?? 0;
  const days = Math.round((Date.parse(meta.toIso) - Date.parse(meta.fromIso)) / 86_400_000);
  const dropRows = Object.entries(scrubbed.drops).map(([k, v]) => `| ${k} | ${v} |`).join("\n");
  const compare = meta.compare
    ? `| Deduplication | ${meta.compare.onlyInPrevious} keys only in previous, ${meta.compare.onlyInCurrent} only in current (against ${meta.compare.previous}) |`
    : "| Deduplication | not compared in this run (pass --compare) |";
  const markdown = `# Indexer run report

Network ${meta.network}, ${meta.fromIso} to ${meta.toIso} (ledgers ${meta.range.from}-${meta.range.to}), run on ${meta.runDate}.
Horizon served ledgers from ${meta.retentionFloor} on that day.

| Metric | Measured |
|---|---|
| Coverage | ${meta.accounts} accounts, ${days} days |
${compare}
| Dropped records with reason | ${Object.values(scrubbed.drops).reduce((a, b) => a + b, 0)} (table below) |
| Coverage ratio | ${ratio.toFixed(2)} (${written} volume observations from ${read} payment-family records) |
| Muxed share | ${muxed} of ${read} (${(read === 0 ? 0 : muxed / read).toFixed(2)}), ${c["muxed_resolved"] ?? 0} resolved |
| Cost | ${requests} requests, ${totalObs === 0 ? "n/a" : (requests / totalObs).toFixed(2)} per observation, ${(meta.wallClockMs / 1000).toFixed(0)} s wall clock |

## Drops

| Reason | Count |
|---|---|
${dropRows || "| none | 0 |"}

## Limits

- Reads the SDF public Horizon, which serves about a year of history and is on its way to end-of-life (issue #3).
- Followed accounts chosen by the tracked selection rule, not by a pilot's real counterparties.
- Soroban asset transfers to one account in one invocation are summed; memos are recorded for text memos only.
`;
  const json = JSON.stringify({ meta, ...scrubbed }, null, 2);
  return { json, markdown };
}
```

```ts
#!/usr/bin/env node
import { readFile, writeFile } from "node:fs/promises";
import { join } from "node:path";
import { parseArgs } from "node:util";
import { selectAccounts } from "./accounts.js";
import { systemClock } from "./clock.js";
import { Counters } from "./counters.js";
import { compareKeys, readKeys } from "./dedupe.js";
import { HorizonClient } from "./horizon/client.js";
import { HorizonReader } from "./horizon/reader.js";
import type { Network } from "./mapper/context.js";
import { renderReport } from "./report.js";
import { backfill } from "./run.js";
import { openSink, outputFileName } from "./sink.js";
import type { LedgerRange } from "./source/types.js";
import { loadState, saveState } from "./state.js";

const NETWORKS: Record<Network, string> = {
  "stellar:pubnet": "https://horizon.stellar.org",
  "stellar:testnet": "https://horizon-testnet.stellar.org",
};

const USAGE = `usage:
  nnt-indexer select-accounts --network <stellar:pubnet|stellar:testnet> --from <ISO> --to <ISO> [--n 100] [--max-appearances 50] --out accounts.txt
  nnt-indexer backfill --network <net> --accounts <file> --from <ISO> --to <ISO> [--out-dir out] [--state <file>] [--cache-dir cache] [--force] [--compare <ndjson>] [--min-interval-ms 1250] [--horizon-url <url>]
  nnt-indexer follow --network <net> --accounts <file> [--state <file>] [--cache-dir cache]
  nnt-indexer report --counters <file>`;

interface Io { log(s: string): void; error(s: string): void }

export async function main(argv: string[], env: NodeJS.ProcessEnv, io: Io = console): Promise<number> {
  const [command, ...rest] = argv;
  try {
    switch (command) {
      case "select-accounts": return await cmdSelect(rest, io);
      case "backfill": return await cmdBackfill(rest, io, false);
      case "follow": return await cmdBackfill(rest, io, true);
      case "report": return await cmdReport(rest, io);
      default:
        io.error(USAGE);
        return 2;
    }
  } catch (e) {
    io.error(e instanceof Error ? e.message : String(e));
    return 1;
  }
}

function network(value: string | undefined, io: Io): Network | null {
  if (value === "stellar:pubnet" || value === "stellar:testnet") return value;
  io.error(`--network must be stellar:pubnet or stellar:testnet, received ${String(value)}`);
  return null;
}

function toIsoDay(s: string): string {
  const d = new Date(s);
  if (Number.isNaN(d.getTime())) throw new Error(`not a date: ${s}`);
  return d.toISOString();
}

function horizon(net: Network, opts: { horizonUrl?: string; cacheDir?: string; minIntervalMs?: string }, counters: Counters) {
  const client = new HorizonClient({
    baseUrl: opts.horizonUrl ?? NETWORKS[net],
    clock: systemClock,
    counters,
    ...(opts.cacheDir ? { cacheDir: opts.cacheDir } : {}),
    ...(opts.minIntervalMs ? { minIntervalMs: Number(opts.minIntervalMs) } : {}),
  });
  return new HorizonReader(client, counters);
}

async function cmdSelect(args: string[], io: Io): Promise<number> {
  const { values } = parseArgs({ args, options: {
    network: { type: "string" }, from: { type: "string" }, to: { type: "string" }, n: { type: "string", default: "100" },
    "max-appearances": { type: "string", default: "50" }, out: { type: "string" }, "cache-dir": { type: "string" }, "horizon-url": { type: "string" },
  } });
  const net = network(values.network, io);
  if (!net || !values.from || !values.to || !values.out) { io.error(USAGE); return 2; }
  const counters = new Counters();
  const reader = horizon(net, { horizonUrl: values["horizon-url"], cacheDir: values["cache-dir"] }, counters);
  const range = await reader.resolveRange(toIsoDay(values.from), toIsoDay(values.to));
  const r = await selectAccounts(reader, { range, n: Number(values.n), maxAppearances: Number(values["max-appearances"]) });
  await writeFile(values.out, r.accounts.join("\n") + "\n", "utf8");
  io.log(`selected ${r.accounts.length} of ${r.candidates} candidates over ledgers ${range.from}-${range.to}; excluded ${r.excludedBusy} busy, ${r.excludedMissing} missing; ${counters.get("requests")} requests`);
  return 0;
}

async function cmdBackfill(args: string[], io: Io, follow: boolean): Promise<number> {
  const { values } = parseArgs({ args, options: {
    network: { type: "string" }, accounts: { type: "string" }, from: { type: "string" }, to: { type: "string" },
    "out-dir": { type: "string", default: "out" }, state: { type: "string" }, "cache-dir": { type: "string" },
    force: { type: "boolean", default: false }, compare: { type: "string" }, "min-interval-ms": { type: "string" }, "horizon-url": { type: "string" },
  } });
  const net = network(values.network, io);
  if (!net || !values.accounts) { io.error(USAGE); return 2; }
  const started = systemClock.now().getTime();
  const counters = new Counters();
  const reader = horizon(net, { horizonUrl: values["horizon-url"], cacheDir: values["cache-dir"], minIntervalMs: values["min-interval-ms"] }, counters);
  const accounts = (await readFile(values.accounts, "utf8")).split("\n").map((s) => s.trim()).filter((s) => s.length > 0);
  const statePath = values.state ?? `state-${net.replace(":", "-")}.json`;
  const state = await loadState(statePath, net);
  const retentionFloor = await reader.retentionFloor();
  state.retentionFloor = retentionFloor;

  let fromIso: string;
  let toIso: string;
  let range: LedgerRange;
  if (follow) {
    const latest = await reader.latestLedger();
    const lastDone = Math.max(retentionFloor, ...Object.values(state.accounts).flatMap((a) => a.completed.map((c) => c.to)));
    range = { from: lastDone + 1, to: latest };
    fromIso = systemClock.now().toISOString();
    toIso = fromIso;
  } else {
    if (!values.from || !values.to) { io.error(USAGE); return 2; }
    fromIso = toIsoDay(values.from);
    toIso = toIsoDay(values.to);
    range = await reader.resolveRange(fromIso, toIso);
  }

  const name = follow ? `${net.replace(":", "-")}_follow_${range.from}_${range.to}.ndjson` : outputFileName(net, fromIso, toIso);
  const outPath = join(values["out-dir"], name);
  const sink = openSink(outPath);
  const result = await backfill({
    reader, accounts, range, ctx: { network: net, producerVersion: "0.1.0" }, sink, state,
    saveState: () => saveState(statePath, state), counters, clock: systemClock, force: values.force,
  });
  const { lines } = await sink.close();

  let compare: { previous: string; onlyInPrevious: number; onlyInCurrent: number } | undefined;
  if (values.compare) {
    const cmp = compareKeys(await readKeys(values.compare), await readKeys(outPath));
    compare = { previous: values.compare, onlyInPrevious: cmp.onlyInPrevious.length, onlyInCurrent: cmp.onlyInCurrent.length };
  }
  const meta = {
    network: net, fromIso, toIso, range, retentionFloor, runDate: systemClock.now().toISOString(),
    accounts: accounts.length, wallClockMs: systemClock.now().getTime() - started, ...(compare ? { compare } : {}),
  };
  const { json, markdown } = renderReport(counters.snapshot(), meta);
  await writeFile(outPath.replace(/\.ndjson$/, ".counters.json"), json, "utf8");
  await writeFile(outPath.replace(/\.ndjson$/, ".report.md"), markdown, "utf8");
  io.log(`${lines} observations -> ${outPath}; ${result.accountsDone} accounts done, ${result.accountsSkipped} skipped; ${counters.totalDrops()} drops; ${counters.get("requests")} requests`);
  if (result.duplicateKeys > 0) { io.error(`${result.duplicateKeys} duplicate keys inside one run: a contract question, not a warning`); return 1; }
  if (compare && (compare.onlyInPrevious > 0 || compare.onlyInCurrent > 0)) { io.error("key sets differ between runs"); return 1; }
  return 0;
}

async function cmdReport(args: string[], io: Io): Promise<number> {
  const { values } = parseArgs({ args, options: { counters: { type: "string" } } });
  if (!values.counters) { io.error(USAGE); return 2; }
  const saved = JSON.parse(await readFile(values.counters, "utf8")) as { meta: Parameters<typeof renderReport>[1]; counts: Record<string, number>; drops: Record<string, number>; dropSamples: Record<string, string[]> };
  io.log(renderReport({ counts: saved.counts, drops: saved.drops, dropSamples: saved.dropSamples }, saved.meta).markdown);
  return 0;
}

if (process.argv[1] && /cli\.(js|ts)$/.test(process.argv[1])) {

}
```
