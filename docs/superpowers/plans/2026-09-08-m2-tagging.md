# M2 Tagging Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `packages/tagging`, the pure arithmetic that turns an
observation plus the baseline it is measured against into the next baseline
state and, when the deviation warrants it, a tag decision carrying `g0`, the
channel, the signed surprise and whether the tag is new or a refresh.

**Architecture:** One workspace package depending on `@nonametrust/schema`
alone, so the whole milestone is provable over a fixed corpus without a
database. An observation is read into one or more `(aspect, value)` readings
by a derivation the caller cannot influence; each reading is judged against
its baseline, then clipped, then folded into the next baseline; a surprise
that crosses the noise-adaptive threshold becomes a bounded `g0`, and a live
tag on the same pair is refreshed by maximum plus a saturating increment. The
decayed strength of a live tag is an input, because `strengthAt` lives in
`packages/store`. A third repository gate holds the tagging and store baseline
shapes equal field for field.

**Tech Stack:** TypeScript on Node 22, pnpm workspaces, `zod` via
`@nonametrust/schema`, vitest. No database driver, no clock.

**Spec:** `docs/superpowers/specs/2026-09-08-m2-tagging-design.md`

## Global Constraints

- Node 22 LTS. pnpm workspaces. TypeScript strict mode with `isolatedModules`.
- `exactOptionalPropertyTypes` is on. A field typed as optional cannot be
  assigned `undefined` explicitly.
- Every package's `tsconfig.json` excludes `src/**/*.test.ts` and the seven
  sibling patterns so tests never reach `dist`. Its `tsconfig.test.json`
  **must** set `"exclude": []`, because `extends` inherits the build config's
  exclusion and would otherwise drop tests from typechecking while `tsc` still
  exits zero. This is carried note 5 from M0 and it bit once already.
- Continuous integration runs `pnpm build` **before** `pnpm typecheck`, because
  packages resolve through `dist` with no source fallback. Do not reorder.
  `packages/tagging` imports `@nonametrust/schema` and so needs the schema's
  `dist` to exist before it can typecheck or test.
- A new package brings at least one test in the commit that creates it.
  `vitest run` exits 1 on zero test files, deliberately. Carried note 4 from M0.
- Licence Apache-2.0 on every package.
- All code, comments, identifiers and documentation in English. Board items and
  messages to collaborators in Turkish.
- No tracked file may contain a checksum-valid or shape-valid Stellar account
  identifier. `gates/no-stellar-address.test.ts` enforces it over every tracked
  file. A test needing a real-shaped key generates it at run time.
- **`packages/tagging` imports nothing but `@nonametrust/schema`.** Not
  `@nonametrust/store`, not `kysely`, not `pg`. The boundary is what makes the
  milestone testable without a cluster, and Task 1's test refuses any other
  import specifier in `src`.
- **No database in any test in this package.** No test reads
  `NNT_TEST_DATABASE_URL`, opens a connection or applies a migration. The
  store's suite fails without a database on purpose; this package's suite must
  pass without one, on purpose.
- **Tag strength is never stored, and never computed here.** `tagging` returns
  `g0` and `taggedAt`. The decayed strength of a live tag arrives as an input
  the caller computed with `strengthAt`; nothing in this package reimplements
  that curve.
- **The clock is injected.** `Date.now()` and a no-argument `new Date()` do not
  appear in `packages/tagging/src`. The instant of a tagging call is the `at`
  argument. Task 1's boundary test holds this lexically.
- **No line in `packages/tagging/src` names a date field of an observation**,
  in code or in a comment. `gates/single-date-reader.test.ts` scans this
  package from the day it exists, with no exemption, and matches the names
  inside comments too. The event's instant is read through `datedAt` from
  `@nonametrust/schema` and referred to in prose as "the event's instant".
- **No surprise is ever infinite or NaN.** Arithmetic that cannot produce a
  meaningful number raises `RangeError` before anything reaches the store,
  which is the first of the two refusal shapes M1 left and the one `strengthAt`
  already uses.
- **Every result names the policy version and the calibration version that
  produced it.**

## The numbers, fixed once, here

So that no two tasks disagree about a default. Every policy value below is
uncalibrated: it was chosen so that the parent spec's section 9 scenario, the
day-twelve address change and the day-twenty-one five-hundred-unit request
after small daily payments, behaves as the whitepaper describes. Every
calibration value names the study result it comes from, and Task 3's test
recomputes it from the vendored aggregate.

| Name | Where | v0 value | Origin |
|---|---|---|---|
| `minObservations` | policy | `10` | eleven mornings precede day twelve; ten leaves the baseline warm before the scenario's first deviation |
| `winsorMadMultiple` | policy | `3` | the parent spec's "multiple of MAD", value uncalibrated |
| `scaleFloor.byChannel` | policy | volume `1`, price `0.01`, latency `50`, cluster_proximity `1` | one per continuous channel, in the quantity's own unit, uncalibrated |
| `scaleFloor.byAspect` | policy | `volume/amount/USDC/in: 0.05`, `price/quoted/USDC: 0.05` | the scenario's two aspects; a quarter-unit payment needs a floor below a unit |
| `fastAlpha`, `slowAlpha` | policy | `0.2`, `0.02` | exponential weights of the two timescales, uncalibrated |
| `thresholdBase` | policy | `3` | `θ_tag` at zero noise, in robust z units, uncalibrated |
| `noiseCoefficient` | policy | `1` | how fast `θ_tag` rises with noise, uncalibrated |
| `fleetPrior` | policy | volume `0.5`, price `0.2`, latency `0.5`, cluster_proximity `0.5` | prior relative dispersion per continuous channel; v0 has no fleet |
| `surpriseScale` | policy | `3` | the surprise at which `g0` reaches `1 − 1/e` of its ceiling |
| `categoricalBase` | policy | `0.8` | the `g0` a categorical observation carries before its channel weight |
| `refreshIncrement` | policy | `0.05` | the bounded increment a refresh adds on top of the maximum |
| `g0Ceiling` | policy | `1` | where the increment saturates |
| `unmeasuredChannelWeight` | policy | `0.6227` | latency and price have no study signal; they take the weakest measured weight |
| `channelWeights` | calibration | volume `0.9674`, address_integrity `0.7984`, protocol `0.6496`, cluster_proximity `0.8167`, content `0.6227` | precision at an even prior, add-one smoothed, from the study's 30-day per-signal table |
| `halfLifeMs` | calibration | `14 days` | the pooled median distance of dated hits, `results/distance_hist.csv`; pooled, not per channel |

**Why precision at an even prior.** The study's table gives, per signal, the
share of victims and the share of controls that carried it. Precision is the
share of carriers that are victims, and at the study's own two-to-one control
ratio it would be dominated by the sample design rather than by the signal.
At an even prior it is `v / (v + c)` over the two rates, which is the
quantity the audit's diagnosis asks for: the broad channels S5 and S6 land
near `0.63` and `0.65` because they fire on nearly half of controls, while the
narrow ones land at `0.80` to `0.97` because controls almost never carry
them. Add-one smoothing on both arms exists for one row: S2's control rate is
exactly zero, and an unsmoothed precision of `1.0` would be a claim that a
test payment is never innocent, which nothing measured.

**Why fourteen days.** The parent spec says the half-life ships as a
per-channel parameter whose default is the pooled value, and the study reports
one pooled distribution. Its median is the distance at which half the dated
hits have already happened, `14.01` days, so a tag opened at the median
distance still holds half of `g0` when the loss arrives. The 80th percentile,
`23.4` days, is the TTL's figure and belongs to W7, not to this file.

`packages/tagging/src/boundary.test.ts`:

```ts
import { readdirSync, readFileSync, statSync } from "node:fs";
import { dirname, join, relative, resolve } from "node:path";
import { fileURLToPath } from "node:url";
import { describe, it, expect } from "vitest";

// This package depends on @nonametrust/schema and on nothing else, and that
// is what makes the milestone provable without a database: tagging is
// arithmetic, and arithmetic whose determinism must hold over a fixed corpus
// should not need a cluster to show it. The parent spec's dependency table
// says so; this file is the gate on it, because a dependency added to
// package.json or an import added to a module would otherwise be noticed by
// nobody until the store's suite started failing in here.
//
// Three more properties are held lexically, in the idiom of the root gates.
// The clock is an argument and never read, so the day-twelve to
// day-twenty-one corpus runs in milliseconds. No test opens a database,
// because a suite that needs one would fail for the reason the store's
// deliberately does. And the decayed strength of a tag is an input, so the
// package never names the module that computes it.
const srcDir = fileURLToPath(new URL("./", import.meta.url));
const pkgDir = fileURLToPath(new URL("../", import.meta.url));

const SOURCE = /\.(ts|mts|cts|tsx)$/;
const TEST = /\.(test|spec)\.(ts|mts|cts|tsx)$/;
// Static imports and re-exports with a `from`, bare side-effect imports, and
// dynamic imports of a string literal. A dynamic import of an expression is
// not matched and is refused below by a separate check, so it is not a way
// past.
const SPECIFIER =
  /\b(?:import|export)\b[^"'`;]*?\bfrom\s*["']([^"']+)["']|\bimport\s*["']([^"']+)["']|\bimport\s*\(\s*["']([^"']+)["']\s*\)/g;
const DYNAMIC_EXPRESSION = /\bimport\s*\(\s*[^"')]/;
const CLOCK = /\bDate\.now\s*\(|\bnew\s+Date\s*\(\s*\)/;
const DATABASE = /\bkysely\b|["']pg["']|@nonametrust\/store|NNT_TEST_DATABASE_URL/;

interface SourceFile {
  rel: string;
  abs: string;
  text: string;
  isTest: boolean;
}

function sourceFiles(): SourceFile[] {
  const out: SourceFile[] = [];
  for (const entry of readdirSync(srcDir, { recursive: true, withFileTypes: true })) {
    if (!SOURCE.test(entry.name)) continue;
    const abs = join(entry.parentPath, entry.name);
    // stat follows a symlink; the dirent's own isFile() is false for one.
    if (!statSync(abs).isFile()) continue;
    out.push({
      rel: relative(srcDir, abs),
      abs,
      text: readFileSync(abs, "utf8"),
      isTest: TEST.test(entry.name),
    });
  }
  return out;
}

function specifiers(text: string): string[] {
  const found: string[] = [];
  for (const m of text.matchAll(SPECIFIER)) {
    const spec = m[1] ?? m[2] ?? m[3];
    if (spec !== undefined) found.push(spec);
  }
  return found;
}

function allowed(file: SourceFile, spec: string): boolean {
  if (spec.startsWith("./") || spec.startsWith("../")) {
    // A relative path is allowed only while it stays under src. `../../store`
    // is relative and is exactly the import this gate exists to refuse.
    const target = resolve(dirname(file.abs), spec);
    return target.startsWith(srcDir);
  }
  if (spec === "@nonametrust/schema") return true;
  if (file.isTest && (spec === "vitest" || spec.startsWith("node:"))) return true;
  return false;
}

describe("the package boundary", () => {
  it("scans this file, so the gate cannot pass by scanning nothing", () => {
    expect(sourceFiles().map((f) => f.rel)).toContain("boundary.test.ts");
  });

  it("declares @nonametrust/schema as its only dependency", () => {
    const pkg = JSON.parse(readFileSync(join(pkgDir, "package.json"), "utf8")) as {
      dependencies?: Record<string, string>;
      devDependencies?: Record<string, string>;
      peerDependencies?: Record<string, string>;
      optionalDependencies?: Record<string, string>;
    };
    expect(Object.keys(pkg.dependencies ?? {})).toEqual(["@nonametrust/schema"]);
    expect(pkg.peerDependencies).toBeUndefined();
    expect(pkg.optionalDependencies).toBeUndefined();
    // vitest and typescript come from the root; a package-level devDependency
    // that is not a type package is a runtime dependency in disguise.
    for (const dev of Object.keys(pkg.devDependencies ?? {})) {
      expect(dev, `${dev} is not a @types package`).toMatch(/^@types\//);
    }
  });

  it("imports only @nonametrust/schema, itself, and in tests vitest and node builtins", () => {
    const offenders: string[] = [];
    for (const file of sourceFiles()) {
      if (DYNAMIC_EXPRESSION.test(file.text)) {
        offenders.push(`${file.rel}: dynamic import of a non-literal`);
      }
      for (const spec of specifiers(file.text)) {
        if (!allowed(file, spec)) offenders.push(`${file.rel}: ${spec}`);
      }
    }
    expect(offenders, "these imports leave the boundary:\n" + offenders.join("\n")).toEqual([]);
  });

  it("reads no clock, so the instant of every computation is an argument", () => {
    const offenders: string[] = [];
    for (const file of sourceFiles()) {
      if (file.isTest) continue;
      file.text.split("\n").forEach((line, i) => {
        if (CLOCK.test(line)) offenders.push(`${file.rel}:${i + 1}: ${line.trim()}`);
      });
    }
    expect(offenders, "these lines read the wall clock:\n" + offenders.join("\n")).toEqual([]);
  });

  it("names no database, in tests included", () => {
    const offenders: string[] = [];
    for (const file of sourceFiles()) {
      // This file names the tokens it refuses, in the pattern above. It is
      // skipped here and here only; its imports are still checked above.
      if (file.rel === "boundary.test.ts") continue;
      file.text.split("\n").forEach((line, i) => {
        if (DATABASE.test(line)) offenders.push(`${file.rel}:${i + 1}: ${line.trim()}`);
      });
    }
    expect(offenders, "these lines name a database or the store:\n" + offenders.join("\n")).toEqual([]);
  });
});
```

## Task 2: The payload reading: the aspect vocabulary and the quantity behind it

Implements spec section 3.

**Files:**
- Create: `packages/tagging/src/reading.ts`
- Create: `packages/tagging/src/reading.test.ts`
- Modify: `packages/tagging/src/index.ts`

**Interfaces:**
- Consumes, from `@nonametrust/schema`: `CHANNELS`, `Channel`, `Observation`,
  `PayloadByChannel`, `payloadSchemaFor`, `validateObservation` (tests only).
- Produces:
  - `CONTINUOUS_CHANNELS = ["volume", "price", "latency", "cluster_proximity"] as const`
    and `CATEGORICAL_CHANNELS = ["address_integrity", "protocol", "content"] as const`,
    with `type ContinuousChannel` and `type CategoricalChannel`
  - `interface ContinuousReading { kind: "continuous"; channel: ContinuousChannel; aspect: string; value: number }`
  - `interface CategoricalReading { kind: "categorical"; channel: CategoricalChannel; aspect: string }`
  - `type Reading = ContinuousReading | CategoricalReading`
  - `interface AspectShape { template: string; unitFields: readonly string[]; quantity: string | null }`
  - `ASPECT_SHAPES: Readonly<Record<Channel, readonly AspectShape[]>>`
  - `shapePattern(shape: AspectShape): RegExp`
  - `readObservation(o: Observation): Reading[]`

**What an aspect is, restated for the implementer.** A baseline is a scale.
Two quantities that share a channel but not a scale must not share a
baseline, because a z-score computed across pooled scales measures nothing.
An aspect therefore names the quantity being measured, when the payload
carries more than one, together with the payload fields that fix that
quantity's unit. It never carries the quantity's value. It is derived from
the observation and never supplied by a caller, so an indexer cannot split or
merge a counterparty's history by choosing a string.

- [ ] **Step 1: Write the failing tests**

`packages/tagging/src/reading.test.ts`:

```ts
import { readFileSync } from "node:fs";
import { join } from "node:path";
import { fileURLToPath } from "node:url";
import { describe, it, expect } from "vitest";
import { CHANNELS, validateObservation, type Channel, type Observation } from "@nonametrust/schema";
import {
  ASPECT_SHAPES,
  CATEGORICAL_CHANNELS,
  CONTINUOUS_CHANNELS,
  readObservation,
  shapePattern,
} from "./reading.js";

// The golden fixtures are the schema's, one per channel, and this package
// reads them from the schema package's directory rather than keeping a copy:
// a copy would drift from the contract the indexer is built against, and the
// point of reading them here is that a payload change lands in the fixture
// first and fails this suite second. fileURLToPath, not URL.pathname, for the
// reason the schema's own fixture test gives: pathname is percent-encoded.
const fixtures = fileURLToPath(new URL("../../schema/fixtures/", import.meta.url));

function fixture(channel: Channel): Observation {
  const raw = JSON.parse(readFileSync(join(fixtures, `${channel}.json`), "utf8")) as unknown;
  const result = validateObservation(raw);
  if (!result.ok) throw new Error(`${channel} fixture failed: ${result.errors.join("; ")}`);
  return result.value;
}

function withPayload(o: Observation, payload: Record<string, unknown>): Observation {
  return { ...o, payload: { ...o.payload, ...payload } };
}

describe("the channel partition", () => {
  it("covers every channel exactly once", () => {
    const union = [...CONTINUOUS_CHANNELS, ...CATEGORICAL_CHANNELS].sort();
    expect(union).toEqual([...CHANNELS].sort());
  });

  it("declares at least one aspect shape per channel", () => {
    for (const c of CHANNELS) {
      expect(ASPECT_SHAPES[c].length, `${c} has no shape`).toBeGreaterThan(0);
    }
  });
});

describe("readObservation", () => {
  // The derivation is total: every channel's fixture yields at least one
  // reading, and every reading's aspect matches one of the shapes declared
```

```ts
import {
  payloadSchemaFor,
  type Channel,
  type Observation,
  type PayloadByChannel,
} from "@nonametrust/schema";

/**
 * The four channels that carry a continuous quantity and so have a baseline,
 * and the three that are categorical and tag from day one against no
 * baseline at all. The partition is total over CHANNELS; reading.test.ts
 * holds the union equal to it, so a new channel fails there until it is
 * placed on one side.
 */
export const CONTINUOUS_CHANNELS = ["volume", "price", "latency", "cluster_proximity"] as const;
export const CATEGORICAL_CHANNELS = ["address_integrity", "protocol", "content"] as const;
export type ContinuousChannel = (typeof CONTINUOUS_CHANNELS)[number];
export type CategoricalChannel = (typeof CATEGORICAL_CHANNELS)[number];

export interface ContinuousReading {
  kind: "continuous";
  channel: ContinuousChannel;
  aspect: string;
  value: number;
}

export interface CategoricalReading {
  kind: "categorical";
  channel: CategoricalChannel;
  aspect: string;
}

export type Reading = ContinuousReading | CategoricalReading;

/**
 * The shape of the aspects one channel can produce. `template` names the
 * quantity and, in braces, the payload fields that fix its unit; `quantity`
 * is the payload field whose value is read, null for a categorical channel.
 *
 * The set of shapes per channel is the enumeration the spec asks for. The
 * set of aspect strings is not finite for volume, price or protocol, since an
 * asset code, a unit and an event name are open strings, but every string
 * that can occur matches exactly one shape, and that is the property a
 * reader needs: a new payload field either lands in a template here or it
 * lands nowhere and pools nothing.
 */
export interface AspectShape {
  template: string;
  unitFields: readonly string[];
  quantity: string | null;
}

export const ASPECT_SHAPES: Readonly<Record<Channel, readonly AspectShape[]>> = {
  // 200 XLM in and 200 USDC out are three different scales, not one.
  volume: [{ template: "amount/{assetCode}/{direction}", unitFields: ["assetCode", "direction"], quantity: "amount" }],
  // A quote in USDC and a quote in XLM are not comparable.
  price: [{ template: "quoted/{unit}", unitFields: ["unit"], quantity: "quoted" }],
  // One scale per counterparty.
  latency: [{ template: "latencyMs", unitFields: [], quantity: "latencyMs" }],
  // Two quantities in one payload, one aspect each; amount only when present.
  cluster_proximity: [
    { template: "hops", unitFields: [], quantity: "hops" },
    { template: "amount", unitFields: [], quantity: "amount" },
  ],
  // Categorical. One transition is one aspect; a revert is a second
  // observation on the same aspect, which is what refresh is for.
  address_integrity: [{ template: "transition", unitFields: [], quantity: null }],
  protocol: [{ template: "event/{event}", unitFields: ["event"], quantity: null }],
  content: [{ template: "field/{field}", unitFields: ["field"], quantity: null }],
};

/**
 * A regular expression matching every aspect string the shape can produce.
 * Each braced field admits any non-empty run; the separator is `/`, which a
 * unit or an event name may itself contain, so a field is not anchored on
 * the separator and the match is on the whole string. The aspect is a key
 * and is never parsed back into its fields, so ambiguity of partition costs
 * nothing.
 */
export function shapePattern(shape: AspectShape): RegExp {
  const escaped = shape.template.replace(/[.*+?^$()|[\]\\]/g, "\\$&");
  return new RegExp("^" + escaped.replace(/\{[a-zA-Z]+\}/g, "(.+)") + "$");
}

/**
 * The payload as its channel's validator types it. Every observation that
 * reaches tagging was validated on the wire, but the stored form types the
 * payload as an open record, and re-running the channel validator is the one
 * way to read it with the field names the shapes above name. A payload the
 * validator refuses cannot be read, so it is a RangeError here, before any
 * number is derived from it.
 */
function parsePayload<C extends Channel>(channel: C, payload: unknown): PayloadByChannel[C] {
  const result = payloadSchemaFor(channel).safeParse(payload);
  if (!result.success) {
    const issues = result.error.issues.map((i) => `${i.path.join(".") || "payload"}: ${i.message}`);
    throw new RangeError(`${channel} payload cannot be read: ${issues.join("; ")}`);
  }
  return result.data as PayloadByChannel[C];
}

/**
 * A decimal string, as the contract carries amounts and prices, read as a
 * double. Seven decimals of a Stellar amount fit; a string of four hundred
 * digits does not, and Number() of it is Infinity, which no scale can
 * measure. Refused rather than returned, so that no infinity is constructed
 * here to be caught later.
 */
function decimal(text: string, field: string): number {
  const n = Number(text);
  if (!Number.isFinite(n)) throw new RangeError(`${field} ${text} does not fit a double`);
  return n;
}

function finite(n: number, field: string): number {
  if (!Number.isFinite(n)) throw new RangeError(`${field} must be finite, got ${n}`);
  return n;
}

function continuous(channel: ContinuousChannel, aspect: string, value: number): ContinuousReading {
  return { kind: "continuous", channel, aspect, value };
}

function categorical(channel: CategoricalChannel, aspect: string): CategoricalReading {
  return { kind: "categorical", channel, aspect };
}

/**
 * Reads an observation into its readings: one per quantity the payload
 * carries, each with the aspect that names the quantity and fixes its unit.
 * The switch is exhaustive over the seven channels and TypeScript holds it
 * so; a channel added to the schema without a case here fails to compile.
 *
 * The aspect is derived here and only here. No caller passes one in, which
 * is what stops a producer from splitting or merging a counterparty's
 * history by choosing a string.
 */
export function readObservation(o: Observation): Reading[] {
  switch (o.channel) {
    case "volume": {
      const p = parsePayload("volume", o.payload);
      return [continuous("volume", `amount/${p.assetCode}/${p.direction}`, decimal(p.amount, "amount"))];
    }
    case "price": {
      const p = parsePayload("price", o.payload);
      return [continuous("price", `quoted/${p.unit}`, decimal(p.quoted, "quoted"))];
    }
    case "latency": {
      const p = parsePayload("latency", o.payload);
      return [continuous("latency", "latencyMs", finite(p.latencyMs, "latencyMs"))];
    }
    case "cluster_proximity": {
      const p = parsePayload("cluster_proximity", o.payload);
      const readings: Reading[] = [continuous("cluster_proximity", "hops", finite(p.hops, "hops"))];
      if (p.amount !== undefined) {
        readings.push(continuous("cluster_proximity", "amount", decimal(p.amount, "amount")));
      }
      return readings;
    }
    case "address_integrity": {
      parsePayload("address_integrity", o.payload);
      return [categorical("address_integrity", "transition")];
    }
    case "protocol": {
      const p = parsePayload("protocol", o.payload);
      return [categorical("protocol", `event/${p.event}`)];
    }
    case "content": {
      const p = parsePayload("content", o.payload);
      return [categorical("content", `field/${p.field}`)];
    }
    default: {
      const unhandled: never = o.channel;
      throw new RangeError(`no reading is defined for channel ${String(unhandled)}`);
    }
  }
}
```

```ts
/**
 * What the study does not speak to. The backtest measured whether evidence
 * exists before a loss, not how an engine should weigh it, so none of these
 * numbers is derivable from it. Each v0 default was chosen so that the parent
 * spec's section 9 scenario behaves as the whitepaper describes: small daily
 * payments, an address change on day twelve that lands in limbo, a
 * five-hundred-unit request on day twenty-one that is held. Every one of
 * them is uncalibrated, and tuning them against live traffic is the shadow
 * evaluation's job. The version is what the champion-challenger arrangement
 * keys on: two policies scoring the same traffic side by side are two
 * versions, and every result names the one that produced it.
 *
 * All fields are readonly. A policy is a value, and a value that one
 * computation could edit for the next would make the version a lie.
 */
export interface Policy {
  readonly version: string;
  /**
   * Below this count a continuous channel produces no tag, whatever the
   * deviation. The categorical channels are independent of it.
   */
  readonly minObservations: number;
  /** An observation is clipped at this multiple of the robust scale before it updates anything. */
  readonly winsorMadMultiple: number;
  /**
   * The floor under the robust scale, in the quantity's own unit, per
   * continuous channel with an override per aspect. Not the quantity's
   * granularity: a floor at the granularity would make a counterparty who
   * always sends exactly the same amount produce a maximal surprise on the
   * first trivial deviation. The two overrides are the scenario's aspects.
   */
  readonly scaleFloor: {
    readonly byChannel: Readonly<Record<ContinuousChannel, number>>;
    /** Keyed `channel/aspect`, for example `volume/amount/USDC/in`. */
    readonly byAspect: Readonly<Record<string, number>>;
  };
  /** Exponential weights of the fast and slow estimators; fast must be the larger. */
  readonly fastAlpha: number;
  readonly slowAlpha: number;
  /** The tag threshold at zero noise, in robust z units. */
  readonly thresholdBase: number;
  /** How fast the threshold rises with the namespace's relative dispersion. */
  readonly noiseCoefficient: number;
  /**
   * v0 has no fleet. The parent spec shrinks namespace statistics toward a
   * fleet-wide prior beneath the minimum count; here the prior is one
   * constant per continuous channel, a relative dispersion, and the count it
   * shrinks over is minObservations. Four declared numbers rather than a
   * prior per (kind, channel, aspect), which would be several hundred
   * invented ones. A real fleet prior is D1.4's work.
   */
  readonly fleetPrior: Readonly<Record<ContinuousChannel, number>>;
  /** The surprise at which g0 reaches 1 − 1/e of its channel's ceiling. */
  readonly surpriseScale: number;
  /**
   * A categorical observation has no surprise. Its g0 is its channel weight
   * times this base, and this base is the one place the spec left open.
   */
  readonly categoricalBase: number;
  /** A refresh adds this on top of the maximum, and it is what saturates. */
  readonly refreshIncrement: number;
  /** Where the increment saturates; a refreshed g0 never exceeds it. */
  readonly g0Ceiling: number;
  /**
   * Latency and price had no signal in the study. Calibration cannot carry
   * what was not measured, so their weight is here, and it is the weakest
   * measured weight so that an unmeasured channel never outranks a measured
   * one.
   */
  readonly unmeasuredChannelWeight: number;
}

function positive(name: string, value: number): void {
  if (!(value > 0) || !Number.isFinite(value)) {
    throw new RangeError(`policy.${name} must be a positive finite number, got ${value}`);
  }
}

function nonNegative(name: string, value: number): void {
  if (!(value >= 0) || !Number.isFinite(value)) {
    throw new RangeError(`policy.${name} must be a non-negative finite number, got ${value}`);
  }
}

function unit(name: string, value: number, closedAtOne: boolean): void {
  const ok = value > 0 && (closedAtOne ? value <= 1 : value < 1);
  if (!ok) throw new RangeError(`policy.${name} must lie in (0, ${closedAtOne ? "1]" : "1)"}, got ${value}`);
}

/**
 * A policy the arithmetic can use. Refused up front, once, rather than
 * discovered as a NaN three functions deep: a zero floor divides, an alpha
 * of one forgets everything, a slow weight above the fast one inverts the
 * two timescales and the divergence they expose.
 */
export function assertPolicy(policy: Policy): void {
  if (!Number.isSafeInteger(policy.minObservations) || policy.minObservations < 1) {
    throw new RangeError(`policy.minObservations must be a positive integer, got ${policy.minObservations}`);
  }
  positive("winsorMadMultiple", policy.winsorMadMultiple);
  for (const [channel, floor] of Object.entries(policy.scaleFloor.byChannel)) {
    positive(`scaleFloor.byChannel.${channel}`, floor);
  }
  for (const [aspect, floor] of Object.entries(policy.scaleFloor.byAspect)) {
    positive(`scaleFloor.byAspect.${aspect}`, floor);
  }
  unit("fastAlpha", policy.fastAlpha, false);
  unit("slowAlpha", policy.slowAlpha, false);
  if (!(policy.fastAlpha > policy.slowAlpha)) {
    throw new RangeError(`policy.fastAlpha must exceed slowAlpha, got ${policy.fastAlpha} and ${policy.slowAlpha}`);
  }
  nonNegative("thresholdBase", policy.thresholdBase);
  nonNegative("noiseCoefficient", policy.noiseCoefficient);
  for (const [channel, prior] of Object.entries(policy.fleetPrior)) {
    nonNegative(`fleetPrior.${channel}`, prior);
  }
  positive("surpriseScale", policy.surpriseScale);
  unit("categoricalBase", policy.categoricalBase, true);
  nonNegative("refreshIncrement", policy.refreshIncrement);
  unit("g0Ceiling", policy.g0Ceiling, true);
  unit("unmeasuredChannelWeight", policy.unmeasuredChannelWeight, true);
}

/**
 * The floor for one aspect: the aspect's own entry when the policy names
 * it, the channel's otherwise. Never zero, by assertPolicy, so the scale
 * built on it is never zero.
 */
export function scaleFloorFor(policy: Policy, channel: ContinuousChannel, aspect: string): number {
  return policy.scaleFloor.byAspect[`${channel}/${aspect}`] ?? policy.scaleFloor.byChannel[channel];
}
```

```ts
export function precisionAtEvenPrior(
  victimHits: number, victimN: number, controlHits: number, controlN: number,

  for (const [name, n] of [["victimHits", victimHits], ["victimN", victimN], ["controlHits", controlHits], ["controlN", controlN]] as const) {
```

**Two rulings the implementer applies.** `m2` is zero at `n = 0`, because a
sum of no squared deviations is zero; `emptyBaseline` says so. The two
robust estimates arrive together at the first observation and are null
together before it, because a spread is a deviation from a location and one
without the other has no meaning; `assertBaseline` refuses a state with one
and not the other.

**What the robust pair is, honestly.** The columns are named `median_est`
and `mad_est`, and a constant-space update cannot produce the sample median
or the median absolute deviation, which need the history the store does not
keep. What is held instead is a location and a spread with the property the
median and the MAD were chosen for: bounded influence. The observation is
clipped at `multiple × scale` around the current location before anything
reads it, and both estimates then move by at most `multiple × scale / n`.
The location is the running mean of clipped values, which is the winsorized
mean, and the spread is the running mean of clipped absolute deviations from
the location. Section 5 of the spec calls the update "Welford for mean and
`m2`" and the pair "robust state"; this is the pair.

```ts
 * packages/store stores it. The two declarations are held equal field for
 * field by gates/baseline-shape.test.ts; a field added here and not there,
 * or there and not here, fails that gate on the day it is added. The type
 * does not live in schema, because schema is the indexer's contract and the
 * engine's internal state has no business in it, and it does not live in
 * store, because this package may not import store.
 *
 * Welford state as count, mean, m2. The robust pair as medianEst, madEst,
 * null together before the first observation and present together from it.
 * The two timescales as the fast and slow pairs, which timescales.ts moves.
 */
export interface BaselineState {
  namespaceId: string;
  channel: string;
  aspect: string;
  count: number;
  mean: number;
  m2: number;
  medianEst: number | null;
  madEst: number | null;
  fastMean: number;
  fastM2: number;
  slowMean: number;
  slowM2: number;
}

/**
 * The state before any observation. m2 is zero because a sum of no squared
 * deviations is zero, which settles the first question 0006 left open; the
 * robust pair is null because there is no location to deviate from yet,
 * which settles the second.
 */
export function emptyBaseline(namespaceId: string, channel: string, aspect: string): BaselineState {
  return {
    namespaceId, channel, aspect,
    count: 0, mean: 0, m2: 0, medianEst: null, madEst: null,
    fastMean: 0, fastM2: 0, slowMean: 0, slowM2: 0,
  };
}

/**
 * A state this arithmetic could have produced. The one shape it refuses is
 * a location without a spread or a spread without a location: a spread is a
 * deviation from a location, and one without the other has no meaning.
 */
export function assertBaseline(state: BaselineState): void {
  if ((state.medianEst === null) !== (state.madEst === null)) {
    throw new RangeError(
      `baseline ${state.channel}/${state.aspect} carries one robust estimate without the other`,
    );
  }
  if (!Number.isSafeInteger(state.count) || state.count < 0) {
    throw new RangeError(`baseline count must be a non-negative integer, got ${state.count}`);
  }
  if (state.count === 0 && state.medianEst !== null) {
    throw new RangeError("a baseline with no observations cannot carry a location");
  }
}

export interface ClipRule {
  multiple: number;
  scale: number;
}

function requireFinite(name: string, value: number): void {
  if (!Number.isFinite(value)) throw new RangeError(`${name} must be finite, got ${value}`);
}

/**
 * The observation clipped to `location ± multiple × scale`. This is the
 * bounded-influence protection: no single observation moves any estimator
 * by more than multiple × scale / n, whatever its value.
 *
 * With no location there is no band, and the value passes through: the
 * first observation is the location.
 *
 * The scale is an argument and not read off the state here, because the
 * scale carries the floor that scale.ts owns, and the floor is what keeps
 * a counterparty with a perfectly regular history from having a band of
 * zero width, which would freeze its baseline at the first value forever.
 */
export function winsorize(x: number, location: number | null, rule: ClipRule): number {
  requireFinite("observation", x);
  if (!(rule.scale > 0) || !Number.isFinite(rule.scale)) {
    throw new RangeError(`scale must be positive and finite, got ${rule.scale}`);
  }
  if (!(rule.multiple > 0) || !Number.isFinite(rule.multiple)) {
    throw new RangeError(`multiple must be positive and finite, got ${rule.multiple}`);
  }
  if (location === null) return x;
  const half = rule.multiple * rule.scale;
  return Math.min(Math.max(x, location - half), location + half);
}

/**
 * The next state after one observation. Clip first, then update: an update
 * that used the raw value and clipped afterwards would already have moved
 * the mean, and the band would have been computed around a location the
 * outlier had already pulled. baseline.test.ts pins the order by a case
 * where the two orders give different numbers.
 *
 * Welford's recursion for mean and m2 in the standard streaming form: every
 * observation counts the same forever, which is what these two are for and
 * why the fast and slow pairs exist beside them.
 *
 * The robust pair: the location is the running mean of clipped values and
 * the spread the running mean of clipped absolute deviations from the
 * location before the update. Neither is the sample median or the median
 * absolute deviation, which constant space cannot hold; both have the
 * property those were chosen for, that one observation moves them by at
 * most multiple × scale / n.
 *
 * The fast and slow pairs are carried unchanged here and moved by
 * timescales.ts, which Task 6 wires in.
 */
export function updateBaseline(state: BaselineState, x: number, scale: number, policy: Policy): BaselineState {
  assertBaseline(state);
  const clipped = winsorize(x, state.medianEst, { multiple: policy.winsorMadMultiple, scale });

  const count = state.count + 1;
  const delta = clipped - state.mean;
  const mean = state.mean + delta / count;
  const m2 = state.m2 + delta * (clipped - mean);

  let medianEst: number;
  let madEst: number;
  if (state.medianEst === null || state.madEst === null) {
    medianEst = clipped;
    madEst = 0;
  } else {
    medianEst = state.medianEst + (clipped - state.medianEst) / count;
    madEst = state.madEst + (Math.abs(clipped - state.medianEst) - state.madEst) / count;
  }

  return { ...state, count, mean, m2, medianEst, madEst };
}
```

```ts
import type { BaselineState } from "./baseline.js";

function requireFloor(floor: number): void {
  if (!(floor > 0) || !Number.isFinite(floor)) {
    throw new RangeError(`scale floor must be positive and finite, got ${floor}`);
  }
}

/**
 * The scale a deviation is measured in: the robust spread, or the floor
 * when the spread is smaller, including when it is zero.
 *
 * The floor is what bounds the zero-spread case. Surprise is a deviation
 * over a scale, and a counterparty whose every payment was the same amount
 * has a spread of exactly zero; the expression is then undefined, and the
 * store refuses the infinity and the NaN it yields. Refusing to tag such a
 * counterparty is a hole an adversary can sit in; falling back to the
 * Welford deviation reintroduces the non-robust estimator at the one point
 * the robust one was chosen for. So the floor, one per (channel, aspect) in
 * the policy, declared uncalibrated, and never the quantity's granularity.
 *
 * Before any observation the spread is null and the scale is the floor, so
 * the first update has a band to clip against.
 */
export function robustScale(state: BaselineState, floor: number): number {
  requireFloor(floor);
  return Math.max(state.madEst ?? 0, floor);
}

/**
 * The signed robust z-score of an observation against its baseline. Signed:
 * the tag gate reads the magnitude, but direction is information a later
 * milestone may want and discarding it here cannot be undone. An
 * unexpectedly large payment is a signal, and so is the small test payment
 * that precedes a loss.
 *
 * Always finite. The scale is never zero, so division cannot produce an
 * infinity; a deviation that itself overflows a double is refused rather
 * than divided, so no infinity is constructed here to be caught later.
 */
export function surpriseOf(x: number, state: BaselineState, floor: number): number {
  if (!Number.isFinite(x)) throw new RangeError(`observation must be finite, got ${x}`);
  if (state.medianEst === null) {
    throw new RangeError(`baseline ${state.channel}/${state.aspect} has no location to measure against`);
  }
  const deviation = x - state.medianEst;
  if (!Number.isFinite(deviation)) {
    throw new RangeError(`deviation of ${x} from ${state.medianEst} does not fit a double`);
  }
  const z = deviation / robustScale(state, floor);
  if (!Number.isFinite(z)) throw new RangeError(`surprise of ${x} is not finite`);
  return z;
}
```

```ts
import type { BaselineState } from "./baseline.js";

export interface Timescale {
  mean: number;
  m2: number;
}

/**
 * One exponentially weighted step. The mean moves by alpha times the
 * deviation; the variance is the standard incremental form,
 * (1 − alpha) × (m2 + alpha × delta²), which is what makes m2 here the
 * weighted variance rather than a sum. The first observation seeds both,
 * because a weighted mean started from zero would spend its first steps
 * climbing toward the data rather than describing it.
 */
export function timescaleStep(prev: Timescale, x: number, alpha: number, first: boolean): Timescale {
  if (!(alpha > 0 && alpha < 1)) throw new RangeError(`alpha must lie in (0, 1), got ${alpha}`);
  if (!Number.isFinite(x)) throw new RangeError(`observation must be finite, got ${x}`);
  if (first) return { mean: x, m2: 0 };
  const delta = x - prev.mean;
  const mean = prev.mean + alpha * delta;
  const m2 = (1 - alpha) * (prev.m2 + alpha * delta * delta);
  return { mean, m2 };
}

/**
 * How far the fast spread has departed from the slow one: the log of their
 * ratio, with the floor added to both so that a zero variance on either
 * side divides nothing and the value is always finite. Zero when they agree,
 * positive when the recent past is noisier than the reference, negative
 * when it is calmer.
 *
 * Exposed and not acted on. Whether the divergence should itself gate a tag
 * is a claim about adversarial behaviour that nothing has measured yet, so
 * this package computes it and carries it out, and tag.test.ts holds that
 * no decision depends on it.
 */
export function timescaleDivergence(state: BaselineState, floor: number): number {
  if (!(floor > 0) || !Number.isFinite(floor)) {
    throw new RangeError(`scale floor must be positive and finite, got ${floor}`);
  }
  const fast = Math.sqrt(state.fastM2) + floor;
  const slow = Math.sqrt(state.slowM2) + floor;
  const divergence = Math.log(fast / slow);
  if (!Number.isFinite(divergence)) {
    throw new RangeError(`timescale divergence of ${state.channel}/${state.aspect} is not finite`);
  }
  return divergence;
}
```

```ts
import type { Policy } from "./policy.js";

/**
 * How little history stands behind a baseline, as a number in (0, 1]: one
 * before any observation, one half at the minimum count, falling toward
 * zero as the count grows and never reaching it. The minimum count is the
 * pseudo-count, so that a counterparty at exactly the threshold of being
 * taggable is scored at half confidence rather than full.
 */
export function uncertaintyOf(count: number, policy: Policy): number {
  if (!Number.isSafeInteger(count) || count < 0) {
    throw new RangeError(`count must be a non-negative integer, got ${count}`);
  }
  return policy.minObservations / (count + policy.minObservations);
}

/**
 * The calibrated g0: weight × (1 − uncertainty) × (1 − exp(−|surprise| / τ)).
 *
 * Bounded by the weight, and so by one, for every finite surprise, because
 * each factor lies in [0, 1]; no clamp is applied afterwards and none is
 * needed. Monotone in |surprise|, because the last factor is; strictly
 * decreasing in uncertainty, because the middle one is. The tag table's
 * finiteness check on g0 is therefore a backstop and never the thing that
 * first notices a problem.
 *
 * The magnitude is read here and the sign is not: direction is information
 * a later milestone may want, and it leaves this package on the result
 * untouched, from surpriseOf and not from here.
 *
 * τ is policy.surpriseScale, the surprise at which g0 reaches 1 − 1/e of
 * its ceiling for a counterparty with no uncertainty. It is uncalibrated.
 */
export function calibrateG0(surprise: number, uncertainty: number, weight: number, policy: Policy): number {
  if (!Number.isFinite(surprise)) throw new RangeError(`surprise must be finite, got ${surprise}`);
  if (!(uncertainty >= 0 && uncertainty <= 1)) {
    throw new RangeError(`uncertainty must lie in [0, 1], got ${uncertainty}`);
  }
  if (!(weight > 0 && weight <= 1)) throw new RangeError(`weight must lie in (0, 1], got ${weight}`);
  const evidence = 1 - Math.exp(-Math.abs(surprise) / policy.surpriseScale);
  return weight * (1 - uncertainty) * evidence;
}
```

    `thresholdBase × (1 + noiseCoefficient × noise)`
  - `type SurpriseVerdict = { kind: "cold"; count: number; minObservations: number } | { kind: "measured"; surprise: number; noise: number; threshold: number; crosses: boolean }`

**What the threshold protects against.** An adversary who cannot lower their
own surprise can try to raise everyone's noise. A fixed threshold makes that
pay; an adaptive one does not. The input is the baseline state already in
hand, so the threshold is a function of state and policy and needs nothing
else.

**Where the fleet prior went.** The parent spec shrinks namespace statistics
toward a fleet-wide prior beneath the minimum count. v0 has no fleet, and a
prior with a unit would need one number per aspect. The statistic that
shrinks here is the relative dispersion, which is dimensionless, so one
constant per continuous channel is a meaningful prior for every aspect of
that channel. The shrinkage weight is the minimum count itself: at exactly
the minimum the noise is the midpoint of observed and prior, and the prior
fades as history accumulates. The four constants are declared uncalibrated
in the policy.

**The verdict is against the baseline before the update.** An observation is
judged against the history it has not yet joined. Task 9 calls this function
first and `updateBaseline` second, and its tests hold the order.

```ts
import type { BaselineState } from "./baseline.js";
import type { Policy } from "./policy.js";
import type { ContinuousChannel } from "./reading.js";
import { robustScale, surpriseOf } from "./scale.js";

/**
 * The namespace's observed noise on this aspect, as the robust scale over
 * the magnitude of its location. Dimensionless, so a quarter-unit payment
 * stream and a thousand-unit one with the same relative spread read the
 * same, which is what lets one prior per channel stand in for a fleet. The
 * floor is added to the location so that a location of zero divides
 * nothing.
 */
export function noiseOf(state: BaselineState, floor: number): number {
  if (state.medianEst === null) {
    throw new RangeError(`baseline ${state.channel}/${state.aspect} has no location to measure noise against`);
  }
  return robustScale(state, floor) / (Math.abs(state.medianEst) + floor);
}

/**
 * The observed noise pulled toward the channel's prior with the weight of
 * the minimum count. At exactly the minimum the two halves are equal; at
 * ten times it the prior is a tenth. This is the parent spec's shrinkage
 * toward a fleet-wide prior, with the prior a declared constant because
 * v0 has no fleet to aggregate and a store read would cross the boundary.
 */
export function shrinkNoise(noise: number, count: number, prior: number, policy: Policy): number {
  if (!(noise >= 0) || !Number.isFinite(noise)) throw new RangeError(`noise must be non-negative and finite, got ${noise}`);
  if (!(prior >= 0) || !Number.isFinite(prior)) throw new RangeError(`prior must be non-negative and finite, got ${prior}`);
  if (!Number.isSafeInteger(count) || count < 0) throw new RangeError(`count must be a non-negative integer, got ${count}`);
  const m = policy.minObservations;
  return (count * noise + m * prior) / (count + m);
}

/**
 * θ_tag: the base threshold raised in proportion to the noise. Where a
 * namespace's observed noise is high the threshold rises with it, so an
 * adversary who cannot lower their own surprise gains nothing by raising
 * everyone's noise. Monotone in the noise and equal to the base at zero.
 */
export function tagThreshold(noise: number, policy: Policy): number {
  if (!(noise >= 0) || !Number.isFinite(noise)) throw new RangeError(`noise must be non-negative and finite, got ${noise}`);
  return policy.thresholdBase * (1 + policy.noiseCoefficient * noise);
}

export type SurpriseVerdict =
  | { kind: "cold"; count: number; minObservations: number }
  | { kind: "measured"; surprise: number; noise: number; threshold: number; crosses: boolean };

/**
 * The verdict on one continuous reading against its baseline as it stands
 * before the reading joins it.
 *
 * Cold start is explicit: below the minimum count there is no verdict, only
 * the count and the bar it fell short of, whatever the value was. This is
 * what makes acceptance criterion 1 a property of the function and not of
 * any caller. A null baseline is a counterparty nobody has seen and is
 * cold at count zero.
 *
 * Above the count: the signed surprise, the shrunk noise, the threshold it
 * yields, and whether the magnitude crosses it. The sign is carried, since
 * direction is information; the gate reads the magnitude.
 */
export function judgeSurprise(
  value: number,
  state: BaselineState | null,
  channel: ContinuousChannel,
  floor: number,
  policy: Policy,
): SurpriseVerdict {
  const count = state === null ? 0 : state.count;
  if (state === null || count < policy.minObservations) {
    return { kind: "cold", count, minObservations: policy.minObservations };
  }
  const surprise = surpriseOf(value, state, floor);
  const noise = shrinkNoise(noiseOf(state, floor), count, policy.fleetPrior[channel], policy);
  const threshold = tagThreshold(noise, policy);
  return { kind: "measured", surprise, noise, threshold, crosses: Math.abs(surprise) >= threshold };
}
```

instant, and it decays from there. A `state` creates a tag the first time it
is seen, and after that it does not create a second one while the first
holds: it refreshes the existing one, and the refresh is what carries the
state forward. `datedAt` is the only reader of a date off an observation and
returns null for a state; this package adds no second reader and uses the
call's own instant for the state path.

**Refresh under saturation, the sentence that must not be left out.** A
refresh moves `taggedAt` forward. If it did not, the new `g0` would be
immediately discounted by the whole elapsed time and the tag would collapse
rather than refresh. Because the clock resets, the thing that stops an
attacker pumping one tag is not the clock. It is the maximum, over the
decayed strength and the fresh `g0`, and the increment, which saturates. A
later writer who replaces the maximum with a sum opens the pump, and a
writer who takes the maximum over the stored `g0` rather than the decayed
strength revives a tag to full at every repeat; both are asserted against
below.

```ts
  }
```

```ts
  if (Number.isNaN(value.getTime())) throw new RangeError(`${name} must be a valid date`);

/**
 * A repeated deviation on an already-tagged pair refreshes rather than
 * stacks.
 *
 * The new strength is the maximum of the decayed current strength and the
 * fresh g0, plus a bounded increment that saturates at the ceiling. Not
 * the sum: a sum is the pump. Not the maximum over the stored g0: together
 * with the moved instant that would revive the tag to full at every repeat.
 *
 * The instant moves forward. If it did not, the new g0 would be discounted
 * by the whole elapsed time at the first read and the tag would collapse
 * rather than refresh. Because the clock resets, the clock is not what
 * stops an attacker; the maximum makes identical repeats idempotent and the
 * increment saturates. Forward only: an observation that arrives late, with
 * an instant behind the tag's, does not move the tag back.
 *
 * A saturated tag refreshes its instant and its count but not its g0.
 */
export function refreshTag(live: LiveTagInput, freshG0: number, instant: Date, policy: Policy): TagRefresh {
  requireStrength("live tag g0", live.g0);
  requireStrength("decayed strength", live.decayedStrength);
  requireStrength("fresh g0", freshG0);
  requireInstant("live tag instant", live.taggedAt);
  requireInstant("instant", instant);
  if (!Number.isSafeInteger(live.refreshCount) || live.refreshCount < 0) {
    throw new RangeError(`refresh count must be a non-negative integer, got ${live.refreshCount}`);
  }

  const taggedAt = new Date(Math.max(live.taggedAt.getTime(), instant.getTime()));
  const refreshCount = live.refreshCount + 1;

  if (live.saturationState === "saturated") {
    return { g0: live.g0, taggedAt, refreshCount, saturationState: "saturated" };
  }
  const raised = Math.max(live.decayedStrength, freshG0) + policy.refreshIncrement;
  const g0 = Math.min(raised, policy.g0Ceiling);
  return {
    g0,
    taggedAt,
    refreshCount,
    saturationState: raised >= policy.g0Ceiling ? "saturated" : "open",
  };
}

interface Versions {
  policyVersion: string;
  calibrationVersion: string;
}

export type TagDecision =
  | ({ kind: "new"; channel: Channel; aspect: string; g0: number; taggedAt: Date; surprise: number | null } & Versions)
  | ({ kind: "refresh"; channel: Channel; aspect: string; g0: number; taggedAt: Date; refreshCount: number; saturationState: "open" | "saturated"; surprise: number | null } & Versions);

export interface ReadingInput {
  namespaceId: string;
  observation: Observation;
  reading: Reading;
  /** The instant of this call. A state's tag is stamped here. */
  at: Date;
  /** The baseline for (namespaceId, reading.channel, reading.aspect), or null when none exists yet. */
  baseline: BaselineState | null;
  /** The live tag on the same pair, or null when none. */
  liveTag: LiveTagInput | null;
  policy: Policy;
  calibration: Calibration;
}

export interface ReadingResult {
  reading: Reading;
  /** The next baseline state; null for a categorical reading, which has none. */
  baseline: BaselineState | null;
  /** Null for a categorical reading. */
  verdict: SurpriseVerdict | null;
  /** Exposed and not acted on; null for a categorical reading. */
  timescaleDivergence: number | null;
  decision: TagDecision | null;
}

/**
 * The instant a tag opened by this observation is stamped at. An event's
 * own instant, through datedAt, the single reader of a date off an
 * observation; for a state datedAt returns null and the call's instant
 * stands in, since a standing condition has no instant of its own and the
 * tag's own taggedAt is what carries it forward from here.
 */
function instantOf(o: Observation, at: Date): Date {
  const dated = datedAt(o);
  if (dated === null) return new Date(at.getTime());
  const instant = new Date(dated);
  requireInstant("event instant", instant);
  return instant;
}

function decide(input: ReadingInput, g0: number, surprise: number | null): TagDecision {
  const { reading } = input;
  const instant = instantOf(input.observation, input.at);
  const versions: Versions = {
    policyVersion: input.policy.version,
    calibrationVersion: input.calibration.version,
  };
  if (input.liveTag === null) {
    return { kind: "new", channel: reading.channel, aspect: reading.aspect, g0, taggedAt: instant, surprise, ...versions };
  }
  const refreshed = refreshTag(input.liveTag, g0, instant, input.policy);
  return { kind: "refresh", channel: reading.channel, aspect: reading.aspect, ...refreshed, surprise, ...versions };
}

/**
 * One reading, judged and folded in. This is the pure function the spec
 * describes: in, the reading, the baseline for its pair, the live tag with
 * its strength now, the policy and the calibration; out, the next baseline
 * and either no decision or a decision.
 *
 * On a continuous channel the order is fixed and tag.test.ts holds it:
 * judge against the baseline as it stands, then clip and update. The
 * verdict is cold below the minimum count and produces nothing; the update
 * happens regardless, because a cold baseline is exactly the one that needs
 * the observation. The uncertainty g0 carries is the history before this
 * observation, like the verdict.
 *
 * On a categorical channel there is no baseline, no surprise and no
 * threshold: the observation tags from day one at its channel weight times
 * the policy's categorical base, and a live tag on the pair is refreshed.
 */
export function tagReading(input: ReadingInput): ReadingResult {
  assertPolicy(input.policy);
  assertCalibration(input.calibration);
  requireInstant("at", input.at);
  const { reading, policy, calibration } = input;
  const weight = channelWeight(reading.channel, calibration, policy);

  if (reading.kind === "categorical") {
    const g0 = weight * policy.categoricalBase;
    return { reading, baseline: null, verdict: null, timescaleDivergence: null, decision: decide(input, g0, null) };
  }

  if (input.baseline !== null) {
    assertBaseline(input.baseline);
    const b = input.baseline;
    if (b.namespaceId !== input.namespaceId || b.channel !== reading.channel || b.aspect !== reading.aspect) {
      throw new RangeError(
        `baseline ${b.namespaceId}/${b.channel}/${b.aspect} is not the baseline for ${input.namespaceId}/${reading.channel}/${reading.aspect}`,
      );
    }
  }
  const before = input.baseline ?? emptyBaseline(input.namespaceId, reading.channel, reading.aspect);
  const floor = scaleFloorFor(policy, reading.channel, reading.aspect);

  const verdict = judgeSurprise(reading.value, input.baseline, reading.channel, floor, policy);
  const next = updateBaseline(before, reading.value, robustScale(before, floor), policy);
  const divergence = timescaleDivergence(next, floor);

  let decision: TagDecision | null = null;
  if (verdict.kind === "measured" && verdict.crosses) {
    const g0 = calibrateG0(verdict.surprise, uncertaintyOf(before.count, policy), weight, policy);
    decision = decide(input, g0, verdict.surprise);
  }
  return { reading, baseline: next, verdict, timescaleDivergence: divergence, decision };
}

export interface AspectContext {
  baseline: BaselineState | null;
  liveTag: LiveTagInput | null;
}

export interface TaggingInput {
  namespaceId: string;
  observation: Observation;
  at: Date;
  /** Keyed by aspect. An aspect with no entry is one nobody has seen. */
  contexts: ReadonlyMap<string, AspectContext>;
  policy: Policy;
  calibration: Calibration;
}

export interface TaggingResult {
  readings: ReadingResult[];
  policyVersion: string;
  calibrationVersion: string;
}

const UNSEEN: AspectContext = { baseline: null, liveTag: null };

/**
 * An observation, read into its readings and each one tagged against its
 * own context. The caller supplies the contexts by aspect; it learns which
 * aspects to fetch from readObservation, which is the same derivation this
 * function runs, so the two cannot disagree about the key.
 */
export function tagObservation(input: TaggingInput): TaggingResult {
  assertPolicy(input.policy);
  assertCalibration(input.calibration);
  requireInstant("at", input.at);
  const readings = readObservation(input.observation).map((reading) => {
    const context = input.contexts.get(reading.aspect) ?? UNSEEN;
    return tagReading({
      namespaceId: input.namespaceId,
      observation: input.observation,
      reading,
      at: input.at,
      baseline: context.baseline,
      liveTag: context.liveTag,
      policy: input.policy,
      calibration: input.calibration,
    });
  });
  return {
    readings,
    policyVersion: input.policy.version,
    calibrationVersion: input.calibration.version,
  };
}
```

## Task 10: The third repository gate: the two baseline shapes agree field for field

Implements spec section 2, the crack and the gate that closes it.
Acceptance criterion 6, the tagging and store baseline shapes agree field for
field, is this task's gate.

**Files:**
- Create: `gates/baseline-shape.test.ts`
- Modify: `README.md` (the `## Gates` list and the `What is here` table)

**Interfaces:**
- Consumes: the `export interface BaselineState { … }` declarations in
  `packages/tagging/src/baseline.ts` (Task 4) and
  `packages/store/src/repositories/baseline.ts` (M1), read as text.
- Produces: a repository-root gate in the idiom of the two beside it:
  lexical, self-checking, refusing to report green when it finds nothing to
  compare.

**Why the type is declared twice and gated, rather than declared once.** The
baseline state's type lives in `packages/store`, and its own comment says it
is the shape M2's arithmetic will produce. `tagging` cannot import `store`,
so the shape is declared twice and the two would drift. It does not move to
`schema`, because `schema` is the indexer's contract and the engine's
internal state has no business in it. So `tagging` owns the shape, `store`
keeps its own storage shape, and this gate asserts the two agree field for
field. A field added to one and not the other fails on the day it is added,
which is the same reason the other two gates exist: the property is true
today and nothing would notice when it stopped being.

The comparison is lexical and not through the type checker on purpose. A
root test that imported both modules would pull `kysely` and `pg` into the
gate's program and would need `store`'s `dist`, and a mutual-assignability
check would pass for two declarations that name the same fields in different
words. Field names and their written types, compared as strings, are what
"field for field" means.

```ts
import { readFileSync } from "node:fs";
import { join } from "node:path";
import { fileURLToPath } from "node:url";
import { describe, it, expect } from "vitest";

// A baseline's state is declared twice: once in packages/tagging, whose
// arithmetic produces it, and once in packages/store, which stores it.
// tagging may not import store, because that dependency would put a
// database under every tagging test, and the shape does not belong in
// schema, which is the indexer's contract. Two declarations drift, and
// nothing would notice on the day they did: a field added to the store's
// row and not to the arithmetic would be written as its column default on
// every upsert, with no error anywhere. This gate reads both declarations
// as text and holds them equal field for field, name and written type.
//
// Lexical, like the two gates beside it. Importing the store module here
// would bring its driver into the gate's program and make the gate depend
// on a build; and a type-level assignability check passes for two
// declarations that spell one field differently, which is exactly a drift.
const root = fileURLToPath(new URL("../", import.meta.url));
const DECLARATIONS = {
  tagging: "packages/tagging/src/baseline.ts",
  store: "packages/store/src/repositories/baseline.ts",
} as const;

/**
 * The fields of the one `export interface BaselineState { … }` block in a
 * source, each as `name: type`, sorted. A comment inside the block is
 * dropped; a field is a line ending in a semicolon.
 */
function fieldsOf(source: string, where: string): string[] {
  const block = /export interface BaselineState \{([\s\S]*?)\n\}/.exec(source);
  if (!block) throw new Error(`${where}: no \`export interface BaselineState {\` block found`);
  return block[1]!
    .split("\n")
    .map((line) => line.replace(/\/\/.*$/, "").trim())
    .filter((line) => line.length > 0 && !/^(\/\*|\*)/.test(line))
    .map((line) => line.replace(/;$/, ""))
    .sort();
}

function declared(which: keyof typeof DECLARATIONS): string[] {
  return fieldsOf(readFileSync(join(root, DECLARATIONS[which]), "utf8"), DECLARATIONS[which]);
}

describe("the baseline shape", () => {
  // A comparison of two empty lists is green for free. The gate vouches for
  // nothing until it has found the fields the arithmetic is known to carry.
  it("is found in both packages with the Welford fields in each, so the gate cannot pass by comparing nothing", () => {
    for (const which of ["tagging", "store"] as const) {
      const fields = declared(which);
      expect(fields, `${DECLARATIONS[which]} declares no fields`).not.toEqual([]);
      for (const f of ["count: number", "mean: number", "m2: number"]) {
        expect(fields, `${DECLARATIONS[which]} lacks ${f}`).toContain(f);
      }
    }
  });

  it("agrees field for field between packages/tagging and packages/store", () => {
    expect(declared("tagging")).toEqual(declared("store"));
  });

  // The extractor is what the gate rests on, so it is checked against a
  // drift it can see: one field more on one side.
  it("is compared by an extractor that tells two shapes apart", () => {
    const a = "export interface BaselineState {\n  count: number;\n  mean: number;\n}\n";
    const b = "export interface BaselineState {\n  count: number;\n  // a comment\n  mean: number;\n  extra: number | null;\n}\n";
    expect(fieldsOf(a, "a")).toEqual(["count: number", "mean: number"]);
    expect(fieldsOf(b, "b")).toEqual(["count: number", "extra: number | null", "mean: number"]);
    expect(fieldsOf(a, "a")).not.toEqual(fieldsOf(b, "b"));
    expect(() => fieldsOf("export interface Other {}", "c")).toThrow(/BaselineState/);
  });
});
```

```ts
// The six acceptance criteria of M2, from the design's section 14:
//
//   1. No tag is produced below the minimum observation count.
//   2. A repeated deviation refreshes rather than stacks.
//   3. One extreme observation cannot move a baseline past its bound.
//   4. A state observation never yields two tags inside one window.
//   5. No surprise is ever infinite or NaN, at any MAD including zero.
//   6. The tagging and store baseline shapes agree field for field.
//
// The per-module suites hold each in isolation: 1 in threshold.test.ts, 2
// and 4 in tag.test.ts, 3 in baseline.test.ts, 5 in scale.test.ts, 6 in
// gates/baseline-shape.test.ts. This file runs them together on one corpus,
// in the order the engine will, so that a criterion cannot be met by a
// component that no longer composes with its neighbours. The clock is a
// column of the corpus: twenty-two simulated days run in milliseconds.

const policy = POLICY_V0;
const calibration = CALIBRATION_V0;
const namespaceId = "11111111-1111-4111-8111-111111111111";
const fixtures = fileURLToPath(new URL("../../schema/fixtures/", import.meta.url));

function fixture(rel: string): Observation {
  const raw = JSON.parse(readFileSync(join(fixtures, rel), "utf8")) as unknown;
  const result = validateObservation(raw);
  if (!result.ok) throw new Error(`${rel}: ${result.errors.join("; ")}`);
  return result.value;
}

/** An event fixture re-dated to `instant` with a source reference of its own. */
function eventAt(o: Observation, instant: string, ref: string, payload?: Record<string, unknown>): Observation {
  return {
    ...o,
    observedAt: instant,
    source: { ...o.source, ref, fetchedAt: instant },
    ...(payload === undefined ? {} : { payload }),
  } as Observation;
}

const day = (d: number, time: string): string => `2026-09-${String(d).padStart(2, "0")}T${time}`;
const AMOUNTS = ["0.2500000", "0.2600000", "0.2400000"];
const QUOTES = ["0.25", "0.26", "0.24"];

interface Entry {
  day: number;
  at: Date;
  observation: Observation;
}

function corpus(): Entry[] {
  const volume = fixture("volume.json");
  const price = fixture("price.json");
  const trustline = fixture("protocol.json");
  const away = fixture("day-twelve/address-moved-away.json");
  const back = fixture("day-twelve/address-moved-back.json");
  const entries: Entry[] = [];
  for (let d = 1; d <= 22; d++) {
    const morning = day(d, "08:00:05.000Z");
    entries.push({
      day: d, at: new Date(morning),

    entries.push({
      day: d, at: new Date(morning),
      observation: eventAt(volume, morning, `op:sub:${d}`, { amount: "5.0000000", assetCode: "XLM", direction: "in" }),
    });
    const quoteAt = day(d, "08:00:00.412Z");
    entries.push({
      day: d, at: new Date(quoteAt),
      observation: eventAt(price, quoteAt, `req:quote:${d}`, { quoted: d === 21 ? "500" : QUOTES[d % 3]!, unit: "USDC" }),
    });

    // the same one; a state is not re-emitted, it holds.

      const at = day(5, "08:30:00.000Z");
      entries.push({

interface HeldTag {
  g0: number;
  taggedAt: Date;
  refreshCount: number;
  saturationState: "open" | "saturated";
}

// The caller's arithmetic, mirrored: strengthAt lives in packages/store.
function decayedAt(tag: HeldTag, at: Date): number {
  const elapsed = at.getTime() - tag.taggedAt.getTime();
  if (elapsed <= 0) return tag.g0;
  return tag.g0 * Math.pow(0.5, elapsed / calibration.halfLifeMs);
}

interface Step extends Entry {
  result: TaggingResult;
}

/**
 * The loop the engine will run: for each entry, fetch the baseline and the
 * live tag for every aspect the observation reads into, tag, and store what
 * came back. Baselines and tags are keyed by channel and aspect within the
 * one namespace.
 */
function run(): Step[] {
  const baselines = new Map<string, BaselineState>();
  const tags = new Map<string, HeldTag>();
  const steps: Step[] = [];
  for (const entry of corpus()) {
    const contexts = new Map<string, AspectContext>();
    for (const r of readObservation(entry.observation)) {
      const key = `${r.channel}/${r.aspect}`;
      const tag = tags.get(key);
      contexts.set(r.aspect, {
        baseline: baselines.get(key) ?? null,
        liveTag: tag === undefined ? null : { ...tag, decayedStrength: decayedAt(tag, entry.at) },
      });
    }
    const result = tagObservation({
      namespaceId, observation: entry.observation, at: entry.at, contexts, policy, calibration,
    });
    for (const x of result.readings) {
      const key = `${x.reading.channel}/${x.reading.aspect}`;
      if (x.baseline !== null) baselines.set(key, x.baseline);
      const d = x.decision;
      if (d !== null) {
        tags.set(key, {
          g0: d.g0, taggedAt: d.taggedAt,
          refreshCount: d.kind === "refresh" ? d.refreshCount : 0,
          saturationState: d.kind === "refresh" ? d.saturationState : "open",
        });
      }
    }
    steps.push({ ...entry, result });
  }
  return steps;
}

interface Made {
  day: number;
  channel: string;
  aspect: string;
  decision: TagDecision;
}

function decisionsOf(steps: Step[]): Made[] {
  return steps.flatMap((s) =>
    s.result.readings
      .filter((r) => r.decision !== null)
      .map((r) => ({ day: s.day, channel: r.reading.channel, aspect: r.reading.aspect, decision: r.decision! })),
  );
}

/** The store's check constraints on the baseline table, restated in value. */
function satisfiesStoreChecks(s: BaselineState): boolean {
  const finite = (x: number): boolean => Number.isFinite(x);
  return (
    Number.isSafeInteger(s.count) && s.count >= 0 &&
    finite(s.mean) && finite(s.m2) && s.m2 >= 0 &&
    (s.medianEst === null || finite(s.medianEst)) &&
    (s.madEst === null || (finite(s.madEst) && s.madEst >= 0)) &&
    (s.medianEst === null) === (s.madEst === null) &&
    finite(s.fastMean) && finite(s.fastM2) && s.fastM2 >= 0 &&
    finite(s.slowMean) && finite(s.slowM2) && s.slowM2 >= 0
  );
}
```

```markdown
## Tagging

`packages/tagging` is where a baseline is defined, where a surprise is
measured against it, and where a tag's `g0` comes from. It depends on
`schema` alone and its suite needs no database:

    pnpm --filter @nonametrust/tagging test

The shape is a pure function: in, an observation, the baseline for its
`(namespace, channel, aspect)`, the live tag on that pair with its strength
at this instant, and the policy and calibration in force; out, the next
baseline and either no decision or a decision carrying `g0`, the channel,
the signed surprise and whether the tag is new or a refresh. The decayed
strength is an input, computed by the caller with the store's `strengthAt`,
because the two packages may not depend on each other and the curve must
have one definition. The aspect is derived from the observation and never
supplied, so a producer cannot split or merge a counterparty's history by
choosing a string.

Two files carry the numbers. `src/calibration.ts` holds what the study
measured, the channel weights and the pooled half-life, each entry naming
its source, and a test recomputes every entry from the aggregate tables
vendored under `fixtures/study/`. `src/policy.ts` holds what the study does
not speak to, and every entry there is declared uncalibrated, its default
chosen to make the design's day-twelve to day-twenty-one scenario behave.
The half-life is one pooled value for every channel and is not calibrated
per channel, pending D1.4. Both files are versioned and every result names
the two versions that produced it.

`src/acceptance.test.ts` runs the six M2 criteria together on one corpus,
that scenario, in milliseconds.
```

## Notes for the executor

Six things are known to need a decision or a message at execution time, and
none of them is a placeholder in the tasks above; each is a consequence the
tasks already implement and that a neighbour must hear about.

1. **M1's `TagRepository.refresh` cannot store what `refreshTag` returns.**
   It takes `greatest(g0, new)` over the *stored* `g0` and does not move
   `tagged_at`. Task 9's test "reads the decayed strength and not the stored
   g0" is the reason: together with a moved instant, `greatest` over the
   stored value revives a tag to full at every repeat. M2 writes nothing to
   the database, so nothing here changes the repository; M3's engine must
   write a refresh that stores the decision's `g0`, `taggedAt`,
   `refreshCount` and `saturationState` as returned, and this must be on
   M3's card before its plan is written. Say so in the ledger.
2. **The `tag` table has no `aspect` column.** The spec keys the live tag
   on `(namespace, channel, aspect)`, and `TagDecision` carries the aspect.
   The store's `StoredTag` carries the channel only. Finding the live tag
   for a pair is therefore M3's problem and probably a migration; Task 10's
   gate covers the baseline shape and says nothing about the tag's. Record
   it as carried.
3. **The robust pair is not the sample median and MAD.** `median_est` holds
   the winsorized running mean and `mad_est` the winsorized running mean
   absolute deviation, which are what constant space allows and which have
   the bounded-influence property the names were chosen for. Task 4's
   docstring says so; the ledger should too, so that nobody later "fixes"
   the estimator into one that needs the history the store does not keep.
4. **The fleet prior is four numbers, not seven, and the categorical base is
   one.** The spec says seven, one per channel. A prior for a channel with
   no baseline is a number nothing reads, so the prior is declared for the
   four continuous channels and the categorical channels take
   `categoricalBase`, one number, times their weight. The spec has no rule
   for a categorical `g0` at all; this is the one chosen, and it is in the
   policy file with the others, uncalibrated.
5. **A saturated tag refreshed is revived to the ceiling.** Spec section 10
   says a saturated tag refreshes its instant and its count but not its
   `g0`, and `refreshTag` does exactly that. The consequence is that once a
   pair is saturated, a repeat brings it back to the ceiling with a fresh
   instant. That is bounded, which is what saturation means, but it is
   worth a sentence in the ledger.
6. **The instant of an event's tag is the event's, and the caller's `at`
   may be later.** The decayed strength is computed at `at`, the refreshed
   `taggedAt` is the event's instant or the tag's, whichever is later. For
   a synchronous path the two are minutes apart and the difference is a
   rounding; for a backfill they may be days apart, and the maximum then
   compares a strength decayed to `at` against a `g0` stamped earlier. Held
   conservative, and stated here so M3 chooses its `at` on purpose.

Nothing else is deferred. No step says "handle errors appropriately" or
"write tests for the above".
